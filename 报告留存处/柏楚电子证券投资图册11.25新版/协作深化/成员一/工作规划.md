# 成员一工作规划

2026-11-26，用户在会话中认可分步规划。本轮聚焦柏楚电子商业模式与护城河。成员二衔接历史财务与现金，成员三维护预测与估值，成员四整合共用正文和页面，刘翔宇复核原页与因果强度。

工作分支为 `codex/bochu-member1-business-moat`，起点是已发布的 `main` 提交 `84b3cf8`。该提交与默认分支 `08bbe1b` 的 11.25 版正式稿、离线包、第四轮验收和柏楚账本一致。阶段完成后，将产物、材料缺口和实际确认写入 [步骤完成记录](步骤完成记录.md)。

## 1. 确定议题和基线

**任务与验收**　以 [11.25 正式稿](../../../柏楚电子证券投资分析报告11.25新版.md)、[第二轮反方与改判](../../第二轮/反方与改判.md) 和 [第四轮验收](../../第四轮/验收记录.md) 为现有输入。登记材料的版本与采纳状态，确认以下问题的优先级。

1. 标准品安装与整机工艺验证各需要什么工作。
2. 整机厂为什么可能继续采购，柏楚如何按合同取得收益。
3. 成熟切割、高功率与软硬一体、焊接或精密微加工的优势分别证实到哪一步。

| 待补材料 | 为什么需要 |
| --- | --- |
| 附件指向的 `D:/投资学/会话交接/CURRENT.md` 中与成员一有关的片段，或等效的最新交接。 | 核对上轮做到哪里、已采用哪些结论、还有哪些问题及对应负责人。该路径在本机不可用。 |
| 团队如已有本议题合同、更新的护城河补强稿或审核批注，提供对应文件和采用状态。 | 核对需要接续的段落和判断，避免重复写作或误把待审稿作为基线。 |

**人工确认**　若已有更新材料，请给出路径或相关片段和版本。若没有更新，以 `84b3cf8` 及上述顺序结清本步。若有更优先的问题，在此步记录。

## 2. 核对原件和证据

**任务与验收**　逐项核对 2019–2025 年报、来源指纹、当前 ReviewStore 和已审底稿。证据表写明原稿位置、PDF 物理页、段落或行列、计算入口、支持边界、反方和改判条件。已能定位 2024 年报 p26 和 2025 年报 p29 的两组销量原格。

| 待补材料 | 为什么需要 |
| --- | --- |
| 同整机厂、同机型、同规格的采购重选记录，标明留用、替换或停产。 | 用实际发生重选的批次定义续购分母，区分产品升级、行业需求与留用。 |
| 同材料、功率和验收标准下的样件或换装记录，例如调试工时、一次验收、返工或停机，附测试条件。 | 检验工艺复用是否实际节约整机验证工作，以及开放接口和替代方案能否同样达标。 |
| 同批次控制系统与切割头等硬件的订单或验收匹配，含初装、换件、备件的区分，及可比的折扣后净价、质保或服务条款。 | 识别实际配套及收费责任，判断组别销量上升是否同时对应配套和同规格净价改善。 |
| 如有焊接或精密微加工的样件、验收或重复采购记录，提供适用工件和批次。 | 区分已有产品方案、单个项目验证和持续复制交付。 |

**人工确认**　有获准使用的样本时，说明适用范围。保留同一批次和关键字段即可。缺少样本时，列明公开材料能支持的较窄判断，其余记为待证。
