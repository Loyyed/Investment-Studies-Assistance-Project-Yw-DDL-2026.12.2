# 第一轮复算入口

程序使用 Python 3.10 或更新版本。提取依赖 PyMuPDF，复核依赖 pypdf。本机使用 Python 3.12 和 PyMuPDF 1.28.2。命令从本目录运行，默认读取协作工程柏楚公司的七份原件。也可用 `--annual-dir` 指定保存相同文件名和 SHA-256 的原件目录。

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B .\recalculate.py
& 'D:/Anaconda/python.exe' -X utf8 -B .\verify_round.py
```

如需保留现有 CSV，复算和验证均可指定 `--output <目录>`。复算按年读取原件和来源清单、生成底表、运行当前 Fact 校验，再执行 Decimal 计算。验证器检查已生成 CSV，并独立打开索引中的 PDF。年报原件和人工核验账本以只读方式使用。CSV 为带 BOM 的 UTF-8。

## 文件与列

| 入口 | 用途 |
| --- | --- |
| [年报索引](年报索引.csv) | 路径、SHA-256、可获日期、页数、相关原表物理页及合并范围变更附注。文件名日期为披露可获日。 |
| [清洗底表](清洗底表.csv) | 一格一行。`报告年度` 为所在 PDF 年度，`数据年度` 为原表列对应年度。`原行` 去版面断行空格。`原单位` 与`标准单位`并列。`原字面值`保留原披露格式。 |
| [口径桥](口径桥.csv) · [分类映射](分类映射.csv) | 分别查看数值对读和分类断点。采用值指明适用的比较窗口。例如 2024 年同比采用本报告重列的 2023 年成本，2023 年本期同比仍保留 2023 年报告两列。 |
| [基础统计](基础统计.csv) · [勾稽差额](勾稽差额.csv) | 同比为 100 ×（本期 ÷ 比较期 − 1），毛利率为 100 ×（收入 − 成本）÷ 收入，毛利率变化为百分点。金额按人民币分保留。计算率保留六位小数。适用合计按对应表和项目计算，附注成本分项以合并营业成本为分母。勾稽差额为左侧合计减原表基准。 |
| [缺项表](缺项表.csv) · [既有 Fact 对照](既有Fact对照.csv) | 空白、披露符号、无分项、无可比基数、待解释差额各有标记。Fact 栏显示当前有效原 Fact 与三表同指标的对应位置。 |
| [实施验收](验收记录.md) · [写作规则检查](写作规则检查.md) | 按真实执行身份记录。 |

2019 年管理层分产品和地区表以 0.01 万元显示，转成元后保留原披露精度。与精确合并总额的容差为 50 元。分项相加对表内合计容差为 50 元乘以参与四舍五入的格数。其余分项以原披露金额逐格算差。

固定范围或精确比较基数缺失时，同口径同比留空。公司同比与机械原列计算分别显示。同比基数为零、基数为负或任一单元为空时，复算同比留空。2023 年质保重述改变成本和销售费用的列报。保留原版 2023 年数据及 2024 年报中可获的比较列。
