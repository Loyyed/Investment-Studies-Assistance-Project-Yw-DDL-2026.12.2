# 柏楚电子证券投资图册｜GitHub 归档版

先从本目录的 [离线 ZIP](柏楚电子证券投资图册-离线包.zip) 下载并解压，再双击包内 `index.html`。GitHub 上的 [index.html](index.html) 用于查看归档文件。图册内嵌十章讲解、四类可调现金输入、三条预测路径与价格回代节点。解压后保留整个目录。正文、图件、底表、批注和数值试算在断网时可用，巨潮、交易所、公司及 GitHub 固定版本链接依赖联网。

- 第一次读，沿第一章导图进入采购、历史、现金和估值。每章的解释默认可见。使用「展开各章原文」可以连续读完整归档研究。
- 老师抽查，搜索 `87.34%` 或 `−0.58`，回原始列头、参数和公式。见 [11 月 24 日两条抽查路线](audit/老师抽查路线与改前改后.md)。
- 接手编辑，修改 [十章源](src/chapters/) 中的 `01.md` 至 `10.md`。每章源中的双花括号用于插入交互图，请保留所选位置。共享样式、模板与交互程序放在 [src](src/)。九章原报告及来源映射保存在 [original/report.md](original/report.md)。
- 同源底表、归档图件和证据见 [索引 CSV](data/index.csv)。估值变更需另建模型窗口，原冻结输入和节点按 [版本与指纹](src/versions.json) 审核。
- [第十章研究总结与最终投资建议](src/chapters/10.md)记录团队审阅稿的研究意见与复审触发条件。
- 本地批注按章存到当前浏览器或导出 JSON。独立审核与实际采纳仍需在团队流程中登记。

## 重建

在本目录运行 Python 3.10+，构建无需安装第三方包。

```powershell
python -X utf8 build.py
python -X utf8 验收/verify_snapshot.py
```

重建更新 `index.html`。数据与研究证据快照随包保存，因此也能在另一个目录复跑。调整正文请改章节源；涉及现金、估值或发行人证据时，先更新正式底稿并记录指纹，再接图册。模型原程序位于 GitHub [冻结预测程序](https://github.com/Loyyed/Investment-Studies-Assistance-Project-Yw-DDL-2026.12.2/blob/5f485482174392124261b1654ed102d16c19030c/docs/cases/688188/deep-research-batch-2/forecast.py)。
