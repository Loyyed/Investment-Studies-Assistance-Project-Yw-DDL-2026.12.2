# 柏楚电子 11.25 新版 · 第二轮

**经营结论、商业模式与反方检验｜待刘翔宇审核**

柏楚向激光切割设备制造商提供控制系统、软件和配套硬件。它通过产品交付和按合同验收确认收入。2025 年平面解决方案占主营收入 **59.67%**，占主营毛利额 **62.45%**。软硬件扩张与其他场景增长带来了毛利额增量，主营毛利率降至 **77.92%**。工艺与接口复用可以解释继续采购的理由。续购率、年度结算后同规格净价和切换成本仍待合同层证据。

## 接续边界

第一轮九个受审数据文件按 SHA-256 固定。第二轮所有进入运算的公司数值均来自该底表。2019–2025 年本地发行人完整年报补充合同、交付、售后及管理层解释。原文披露、按原表计算及研究推断分别标识。源年报及主体范围参见[第一轮年报索引](../第一轮/年报索引.csv)。
