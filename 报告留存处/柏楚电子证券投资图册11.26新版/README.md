## 重建

使用Python3.12，安装PyMuPDF、Matplotlib、mistune。直接运行单一入口，会从第三轮章节生成留存输入，再建立完整正式稿与HTML，避免只修改章节而遗漏第四轮实际输入。

    python -X utf8 -B 协作深化/11.26整合/rebuild.py --package

年度原件优先读取原索引路径，原路径不存在时回退第四轮/年报原件同名文件，核SHA后使用。不要用11.25旧构建器覆盖11.26。独立现金与DCF复核脚本分别在成员2核对和成员3核对附件；它们记录原环境路径，本版重建入口使用包内来源。
