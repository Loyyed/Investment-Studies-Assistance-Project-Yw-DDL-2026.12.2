# 五公司工作台

使用仓库根目录下的共享运行时、版本注册、已发布图册和五家公司独立账本。需要 Python 3.10+。在仓库根执行 `python -X utf8 五公司工作台/start.py --open`。默认入口 [五公司首页](http://127.0.0.1:8780/desk/) 和 [五家图册](http://127.0.0.1:8780/atlas/)。`--port` 可指定端口。

首页并列展示涪陵榨菜、安琪酵母、柏楚电子、泡泡玛特和 ISRG。同日估值和报告摘要共用图册的主判断，历史定稿在 /stage17/ 打开。执行根 README 中的公开原件恢复后，到当前 Fact 页核来源状态。团队协作前关注 [覆盖清单](http://127.0.0.1:8780/research/coverage.html) 和 [期后跟踪](http://127.0.0.1:8780/research/follow-up.html)。
