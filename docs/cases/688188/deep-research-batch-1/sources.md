## 发行人原件

[originals.csv](originals.csv) 保存七份年报逐份 Git blob 与 SHA-256，两份三季报、两份半年报及 2026 一季报的来源编号、可获日与页数。2024 年报的协作工作区原路径原先缺件。本轮用经授权档案补回 Git 对象，检出后每份 PDF 同时匹配 Git 对象和来源已登记的 SHA。报表中同时出现母公司表时，抽取在该标题处终止，避免把公司单体现金流误作合并值。季报和招股书副本存本机。
