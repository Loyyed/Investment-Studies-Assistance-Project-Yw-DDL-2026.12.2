- **2026 最近季度。** 2026Q3 单季营收 6.0132 亿元，同比约 +16.51%，毛利率 70.76%，同比降 5.76 个百分点。核心 EBIT 2.6885 亿元，同比约 +3.34%。前三季报告营业利润 12.2603 亿元、核心 EBIT 9.3819 亿元，差 2.8784 亿元。该差额包括财务费用的负数、其他收益、投资及公允价值等，具体见既有利润桥。前三季归母 11.0046 亿元、合并净利 11.0921 亿元，CFO−购建 8.2119 亿元。2026Q3 期末应收＋库存−应付的窄口径为 4.7116 亿元，同期上年为 2.9754 亿元。估值模型用其自身经营资本子集，保留原桥。账面库存从去年末 2.5006 升至 4.0339 亿元，应取得订单覆盖与库龄来区分增长备货和周转承压。[三季报 p1、p6–11](https://static.cninfo.com.cn/finalpage/2026-10-27/1225622322.PDF) · [财务桥](financial-bridge.csv) · [核心 EBIT 桥](../analysis-ebit-bridge.csv)

## 复算与复核

在仓库根执行，下列命令依次恢复核验依赖、生成历史底表和复算冻结估值。`verify_bindings.py` 可用 `--from-archive` 指向已获授权且保持 `companies/` 结构的本机档案。缺季报原件按 [originals.csv](originals.csv) 及源清单恢复。复算环境为 Windows，Python 3.12.14。年度和季报 PDF 通过 `pypdf` 读取。Git 可核七份年报的原始文件对象。预测与估值重算使用标准库。

~~~text
python -X utf8 docs/cases/688188/deep-research-batch-1/verify_bindings.py --from-archive "<授权档案根目录>"
python -X utf8 docs/cases/688188/deep-research-batch-1/extract_history.py
python -X utf8 docs/cases/688188/deep-research-batch-1/reconcile_history.py
python -X utf8 docs/cases/688188/deep-research-batch-1/reproduce_valuation.py
python -X utf8 docs/cases/688188/operating.py
python -X utf8 scripts/build_cases.py --check
python -X utf8 scripts/check_super_atlas.py
~~~

`operating.py` 会重写既有生成物，本轮在隔离工作树重跑，对照 Git 字节一致。原件查询返回 24 条当前发行人 Fact，含 B07-A01 的实际绑定与确认事件。此发行人 ReviewStore 提供 `facts()`，变化行均登记为 AgentCalculated。需要独立确认的量、价、成本和经营机制在图表图中逐项指明。
