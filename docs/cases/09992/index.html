1. 谁决定复购，哪些经营事实支持轮动

收藏者为包装、设计、完整系列和限量形象付钱，送礼者更关心辨识度、价格和门店可得性。公司与艺术家、授权商协作，分别取得形象及联名的合同权利，研发产品并协调外包生产，向终端经直营零售、机器人店、线上和批发销售。自主产品同时包含艺术家 IP 和授权 IP，由商品实现的收入要扣生产、授权费用、运营、租金与履约。品牌能在新品发售时重复把用户引回不同款式，既有渠道和会员的价值在下一款是否卖得动时才可观察。单独授权收入、复购频率、外包成本和限定发货量缺持续同口径，无法当成纯版权收款生意。

2020–2021 年渠道和自主 IP 推动收入由 25.13 增至 44.91 亿元。2022 年只增至 46.17 亿元，成本由 17.32 增至 19.63 亿元、毛利率下行约 3.95 个百分点，证明开店和 IP 投入有可能在需求慢时消耗折扣及周转。2023–2025 年毛绒、热门 IP 与海外扩张推动收入 63.01→130.38→371.20 亿元。2026H1 国内和海外出现分化，然后 Q3 连国内渠道也下行。最强替代解释是同一批消费者追逐下一个爆款，加上铺货能力扩大，增长主要来自更换旗舰、门店变化和折扣。上半年剔除 THE MONSTERS 的增长 40.35%；再剔除星星人仍有 16.09%，线下不全由同一个 IP 拉动。但下半年海外及中国线上负区间要求检验这部分收入能不能继续在低库存压力下兑现。 2020 招股书 · 2025 年报 · 2026 中报物理第26页

2. 把 IP 轮动与渠道变化分开

2026H1 合并收入由 138.763 增至 171.729 亿元。逐个 IP 的归并核对合计增 32.966 亿元，其中 THE MONSTERS 减 3.597 亿元、星星人增 22.606 亿元，星星人相当于全部净增的 68.57%。CRYBABY、DIMOO、SKULLPANDA 和 HIRONO 分别增约 4.14、5.14、3.31、2.80 亿元，MOLLY 减约 4.57 亿元。艺术家 IP 合计与授权 IP 和外采其他相加即集团；把艺术家 IP 合计和具体子行同加会重复。IP 定义不告诉销售单件，因此只能做收入增量，不得把 IP 收入差直接认作销量变化。

用地区×渠道的完整 4×4 交叉表看同一合并增量。PRC 增 39.177 亿元，其中门店 +16.837、机器人店 +1.007、线上 +18.415、批发及其它 +2.918。亚太不含 PRC 减 2.759，美洲减 3.732，欧洲及其它增 0.281 亿元。海外零售门店合计增加 5.202 亿元，海外线上合计减少 11.274 亿元。两个切面各自对合并数，不能将“IP 增长”与“国内线上增长”相加。没有逐地区逐 IP 的真实成交额、货币影响基线和并表细分，不为单个因素分配剩余量。

PRC 零售门店 2025H1/2026H1 末分别 443/455。门店销售 44.059→60.897 亿元，期末店数分母对应 994.57→1,338.39 万元/店，约 +34.57%。以两期中点把 16.837 亿元拆成期末门店数量与单店代理贡献，约 1.40／15.44 亿元。新店开业不满半年、闭店、城市及门店形态、排队客流、促销都会进入后一项。冻模用同期期初期末平均店数的独立代理 +34.22%。原始季报 Q3 只披露整体同比减少 45%–50%，PRC 减25%–30%、亚太减65%–70%、美洲减70%–75%、欧洲及其它减50%–55%，并给 PRC 线下减5%–10%、线上减45%–50%；这是管理账区间，保持季度绝对数空缺。用 2025H2 232.438 亿元和假设权重 35%/50%/65% 得 2026Q3 整体绝对额只能落在条件范围，例如 50% 时 58.11–63.92 亿元。Q4 的全年含义要用两端分别推算，不用 47.5% 冒充单点披露。 地区渠道 · IP 桥 · 店效代理 · 2026Q3 公告

3. 营业成本、渠道费用、库存和可承受折扣

报表销售成本 41.152→52.072 亿元，毛利率 70.34%→69.68%。同期毛利增 22.047 亿元，销售费用增 7.385、管理费用增 1.561，核心 EBIT 从 57.981 增至 71.081 亿元。与报表营业利润 60.437/67.247 亿元的净其它差额分栏，不延长未来利润。费用按性质按附注列示，集团入销货的存货成本增加 10.303 亿元、员工费用增 4.123、短期与可变租赁会计费用增 1.598、使用权折旧增 1.978、电商佣金和平台费减少 0.805、授权费减少 0.749 亿元，存货减值由 0.043 增至 0.228 亿元。性质表含收入成本与销售管理费用的交叉归属，不能再与功能法利润表叠加。管理层将高毛利海外收入下降与授权和采购产品结构共同视为影响毛利的因素，单个 IP、同店或折扣后的单位毛利不可辨。按公司总成本除以合并收入约 30.32%，可作为收入参考的 COGS 率；缺 SKU 件数、折扣、退货与履约单量。

4. 现金利润和股东资本不是同一件事

折旧和短／变租赁费用先从功能分析金额加回，再扣经营和融资两类租赁现金一次。2026H1 IFRS 口径分析营业利润 71.081 亿元，加使用权折旧 4.519、加短／浮动会计租金 6.731、扣经营租赁现金 7.083、扣融资租赁现金 5.029，得 70.220 亿元；2025H1 同口径 58.688 亿元，利润率由 42.29% 降到 40.89%。现金流已计经营租赁，不再减该部分。CFO 59.775→36.373，减现金资本开支和融资租赁后为 53.394→24.103 亿元。同口径实付税 11.896→32.197 亿元，税期错配和库存增加都压低 CFO。用期末贸易应收、存货、应付、合同负债得到窄口径营运资本，并清楚列 ±。2026H1 库存 61.015 亿元、2025H1 22.737 亿元，按期初期末平均年化周转 4.33→1.80 次。不能把端点差额直接加到同期间 CFO 差额。对读2025年报原列补齐阶段15缺项，2025年期末贸易WC41.427亿元、2024年8.036亿元，窄经营资本57.690／16.783亿元，非使用权D&A 5.253亿元。用现金租赁调整 EBIT 和25%税代理得2025窄资本ROIC 341.41%、新增回报235.79%；低资本分母及爆款周期令该数不适合稳定期。独立FCFF代理87.276亿元，对已扣现金购建和融资租金的CFO 90.853亿元，差额留给未见科目。可识别投入、现金和非现金使用权资产分开，若一次性费用现金未能定位则保留差额。

5. 三路径，逐项从实际滚到未来

2026H1 实际 171.729 亿元，冻结 2026H2 基准 123.192 亿元（对 2025H2 倍数 0.53），给全年 294.921 亿元。若 2025Q3 权重 50%，基准 H2 要求 2026Q4 约 59.27–65.08 亿元，明显高于现价的单向门槛，不能把 2026Q4 实际写成已知。2027 基准门店产能增长 7.5%，另一驱动是收入实现与需求留存，并输入销售相关变动租金、门店合同租金、实体履约、折扣毛利和库存回收。压力保留更慢开店与更弱销售获现，库存占用率提高、低价销货压利润；改善要求多个 IP 逐渐接力、成熟店表现稳和更轻库存，只有会员新增与热潮不能同时带来高毛利与低库存。

7. 翻转条件和独立事实

首选判断仍是 166.65 港元高于 143.40 港元，但经营需要过折扣和库存关。竞争性解释是星星人替换 THE MONSTERS 而非可持续扩大的客群。国内和海外的出货与门店质量并未同比同向。下一场验证拿到全年收入、季度绝对额、净折扣、库存库龄、租赁实付和同批成熟店销售。即便全年门店增加，若量只靠更深折扣且库存周转进一步下降，应用联合临界表更新折扣、周转及租金，不把收入增量当正方。Q4 低于对应组合时，条件基准转至现价下方。期后回购根据当日可获时间更新后续快照，由复核人确认股份已注销和价款，不能使用 16:48 的披露推回 16:10 收盘。
