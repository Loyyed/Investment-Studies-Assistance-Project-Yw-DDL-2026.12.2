# ISRG 约 40 页报告素材地图

本轮案例保留可接手的章节口径、图和推导。页数是选定后建议，取舍由团队确认。

| 建议页 | 核心问题 | 现成正文、数据和图 | 缺口与接手任务 |
| --- | --- | --- | --- |
| 1–3 | 为什么业务增长仍未覆盖现价 | 案例首屏、同日三情景、营业和价值结论 | 主笔统一使用 NASDAQ 当地未复权 439.89 及阶段编号 |
| 4–7 | 谁买、谁用、如何售后 | [案例第1节](case.md)，器械耗材、设备、租赁、保修和服务价值链 | 医疗组从监管标签、医院付款及术式经济补同院比较 |
| 8–11 | 扩张与系统压力如何改变消费 | 2019–2020 压力，2021 恢复，2023–2025 扩容，[年度术量和变现](annual-unit-history.csv) | 整理长历史曲线，保留平均装机口径与迁移限制 |
| 12–16 | 收入究竟多来自多少手术、多少设备 | [术量量价桥](instrument-volume-mix.csv) · [美/海外和渠道六格](quarter-revenue-bridge.csv) · [装机贡献](system-placement-bridge.csv) | 收集地区 FX、海外并表和 Ion 单列收入，分出价格与组合 |
| 17–22 | 收费怎样落到现金 | [利润与现金](quarter-cash-accounting.csv) · [按量与固定合同阈值](contract-thresholds.csv) · [租赁分母](lease-revenue-proxy.csv) | 跟踪医院合同、维保、保修、收现和五年残值证据 |
| 23–26 | 投多少资本、等待多久 | [历史资本与回报](historical-capital-proxy.csv)，旧现金流变化、非现金设备转入 | 核实制造现金与库存环节拆分，避免租赁设备重复计价 |
| 27–32 | 三种未来路径怎样相互一致 | [预测底表](forecast.csv) · [阶段17输入和输出](../../research17/US/model.json)，增长、费用、再投资和留出 | 模型组按最新术量和合同数据刷新输入，保持三条路径不混用 |
| 33–37 | 在什么条件下现价可以成立 | [主模型](model.json) · [经营敏感性](sensitivity.csv) · [当前市场反推独立复算](independent-valuation.json)，含同业淘汰及价值桥 | 审核人评估 8% 折现的可辩护性与条件是否可同时达成 |
| 38–40 | 怎样推翻结论并让其他人复查 | [独立复核](independent-review.md) · [证据索引](isrg-evidence-detail.csv) · [跟踪缺口](case.md) | 刘翔宇确认报告主张和再审边界，各角色更新各自公开证据 |
