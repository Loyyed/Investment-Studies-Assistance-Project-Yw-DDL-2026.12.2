# 动效与行业图示

版本 atlas-2026-11-20.3。行业图示由项目实施者以原创 CSS 绘制，分别表现腌制、发酵罐、激光切割、潮玩包装和手术机械臂。暖色低对比用于插画底色，文字与数字保留深色。数据图由本项目的经营底表生成，金额全精度见 CSV 与模型 JSON。

| 动作与触发 | 用途 | 减少动态模式 |
| --- | --- | --- |
| 打开封面，选择五家之一 | 卡片反馈确认选择 | 保留焦点与颜色，关闭位移和入场 |
| 公司页滚动或点击章节 | 进度条和当前章定位 | 立即更新位置，不强制平滑滚动 |
| 选择情景图例 | 显隐系列并保留同源表 | 即时切换，无淡入 |
| 展开现价反推边界 | 查看端点、可行性及每股回代值 | 原生即开、可键盘操作 |
| 打开证据或复制深链接 | 跳到已登记资源与对应章节 | 原生链接和焦点 |
