## 使用方式

每次只启动当前阶段。将 `{公司键}`、`{公司目录}`、`{信息时点}`、`{个人负责路径}`替换为实际值；把本地工作输出保存在成员忽略目录，团队可交付的正文再进入报告留存处。当前已发布研究的窗口是 2026-11-12 各市场当地收盘；更新到其他日期须另版记录。

若使用子代理，先将每项任务说明写成文件：子问题、允许读取的文件及版本、输出文件绝对路径、步骤、结果字段、通过条件、禁止事项与阻断报告方式。交给人实际审阅后再启动；一项基础任务一个子代理，一份文件一个写入者。只将完成状态、关键发现和文件路径返回主 Agent。子代理之间通过文件交接。

## Session 01｜选题与任务合同

> 我们五人准备完成约40页证券投资分析报告。这次研究对象为 `{公司及证券代码}`，我的职责是 `{实际分工}`。请先阅读根 AGENTS、审核与下一步、该公司七章源、report-map、独立复核及当前模型索引。用一条可被经营证据推翻的命题串起报告，说明复用哪些成果、补什么证据、各步骤的依赖与可检验完成标准。将计划写入 `{个人负责路径}/任务合同.md`。信息窗口、核心参数或分工有实质缺口时集中列出，由我们作实际选择；暂不改变原模型和 Fact 状态。

完成时应能回答：研究什么证券、以什么时点判断、最关键的三个变量是什么、什么证据会改变判断、谁负责写入和复核。

## Session 02｜关键原数与口径

> 请按已采用的任务合同，选出直接支撑投资命题的关键原数。先查现有来源索引和当前账本；需要原件时先列恢复计划，再按版本与 SHA-256 恢复。记录主体、报告期、公开日期、PDF物理页与印刷页、表名行列、单位和脚注；区分原披露、派生算术和代理。将候选核对记录落盘到 `{个人负责路径}/关键证据.md`，列明冲突、用途和仍需谁确认。没有读到原件的内容保留实际状态。

可由学生实际追问：这个同比用了哪两列？是合并还是母公司？谁付钱、谁履约？两个分组能相加吗？来源更换后影响哪些主张？

## Session 03｜商业模式、竞争与治理

> 请从已可用的证据解释公司怎样赚钱：谁选择和付款、谁履约、谁负担库存或资本、谁收到现金。将核心优势写成“来源—作用机制—可观察结果—模仿约束—反证”，并检查控制权、资本配置、关联交易和激励如何影响普通股。每项主判断保留一个合理竞争解释和能够区分它的新证据。输出 `{个人负责路径}/机制与治理.md`，以具体经营行动展开论证。

学生在真实阅读后选择优先解释，并说明采纳或否决的依据；相关记录与正式原数核验分别保存。

## Session 04｜历史财务与资本现金

> 请围绕投资命题核对历史变化，把收入、成本费用、经营资本、再投资和现金连起来。优先复用已有底表，只重算受本次口径或证据变化影响的部分。把原数、调整、代理、公式、对账差额和经济解释分开，检查重述、租赁、金融收益、现金税及少数股东。产出 `{个人负责路径}/财务与现金桥.md` 和对应可运行计算文件。未解释差额说明对现金流和估值的影响，不填不明平衡项。

验收动作：学生选一条重要桥用原表手算，记录实际计算与 Agent 结果的差异；如没有实际手算，不登记完成。

## Session 05｜预测、估值与现价要求

> 请依据已经审阅的经营机制和参数版本，复用或调整三条未来路径。逐年说明销量或客户、净价/组合、费用、税、资本投入与回款的关系；新参数列来源、取值理由、上下界和失效条件。FCFF、折现率、终值再投资、币种及普通股权利保持一致，再检验现价要求哪个关键变量达到什么水平。模型写入 `{个人负责路径}/model/`，输出可复算结果及原版本差额，真实不识别的部分保留条件表达。

验收动作：复算现金流恒等式、终值入口投入、股权桥、同日价格和至少一个翻转阈值；先解决已登记的跨环境严格浮点检查问题，再声称精确重建通过。

## Session 06｜独立审阅与有依据的纠错

> 请先把拟委派的审阅任务说明落盘，供我检查。通过后，让独立 Reviewer 只根据原始材料、冻结输入、当前稿件和评价标准检查，不先接受作者对争议的解释。分别保存问题、定位、独立复算、影响和处理建议，Reviewer不直接改原稿。主 Agent 汇总共识与分歧，给出可执行的修订方案。

学生可据实际结果使用 O-G-D-A-V 反馈：

> 当前 `{段落/表/公式}` 出现了 `{可观察问题}`。目标是 `{研究标准}`，差距在 `{具体范围或计算}`。请保留 `{仍有效内容}`，修改 `{受影响部分}`，并用 `{回原件/独立复算/比较}` 验证，保留修订前版本。

## Session 07｜约40页 Markdown 成稿

> 请按团队采用的命题与分工，将本公司材料组织为一份连续报告，正文写入 `报告留存处/YYYY-MM-DD_市场-代码_题名_v0.1.md`，状态为草稿。沿用 writing-v2、author-brief 和该公司素材地图，先画章节论证与证据关系，再分配约40页的工作预算。经营机制、治理、财务、预测、估值与反方互相衔接；每节直接回答问题，保留改变主张含义的限定和重大不利证据。图表引用同版数据及相对图片路径，详细依据和一般研究边界放末尾。

实际验收看论证、证据、计算和可读性。最终页数在后续 PDF 排版中确定，不能用凑字数或重复图表代替分析。

## Session 08｜交付、贡献与复盘

> 请检查成稿、模型、图表和证据是否同版，记录当前通过、未通过及无法验证的项目。列出我在真实对话中提出的质疑、做过的核验、纠错、参数选择和判断，并索引到对应章节、计算文件与实际提交。原始Sessions按工具真实导出，脱敏后用现有收件脚本和清单入本机成员目录。先检查暂存范围，再按已授权目标推送个人分支；PR、团队定稿、合并和向教师提交分别记录实际动作。

团队定稿后统一从 Markdown 转 PDF，检查显式字体、图表标题、分页、中文复制和数字一致性。复盘留下“哪里出错—依据什么发现—如何修改—怎样验证”，以后只读精简 CURRENT 和受影响文件继续工作。

## 会话的最小落盘记录

每次真实会话至少关联：日期、实际参与者与角色、用户目标、读取文件及版本、实际生成文件、关键质疑/修订、验证方法和结果、尚待人作的选择、下一步。完整原始导出另存，模板和摘要不替代它；学生真实贡献从可见行动记录中索引。
