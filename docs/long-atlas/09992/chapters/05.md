# 货架看起来充足，资产负债表要付出多少

## 把使用权会计换成同口径现金

公司在门店和仓库使用的租赁资产可能按合同出现使用权折旧、租赁利息及本金现金，另有短租、低价值标的和与营业相关的可变租金。损益表对不同项目的确认位置有差别，一次性认成某类费用会影响对经营质量的理解。同等租赁实付的两份经营利润比较，会被资产使用权折旧与会计租金的差异干扰。反过来，若估值连续扣合同租赁现金，在权益桥再全额扣同组负债，则重复把经营场地使用义务扣掉。因此模型选择经营租金口径：分析营业利润中将使用权折旧、短租和可变会计租金加回，替成已经支付的经营与融资两类租赁现金。历史、显性及终值均采用包含经营使用店面所需现金的口径。

用2026年中报物理第102页附注15的原列计算。该中期分析营业利润7108.091百万元人民币，使用权折旧451.934，短租和可变会计租金673.120。所有数由原表千元换百万元，费用取绝对额后按加减定义处理。经营租赁现金支出708.255，融资租赁现金支出502.889。公式7108.091加451.934加673.120，减708.255和502.889，得7022.001百万元。2025上半年同口径为5798.069加254.184加513.331，减433.149和263.592，得5868.843。用对应半年的集团收入计算后，核心现金租赁率由42.29%下降至40.89%。两个比较期加回的会计金额、扣减的现金金额分别闭合到各自同一份报表的附注。历史比较采用中报附注的同期实付而非年度金额均摊。 [泡泡玛特2026年中报租赁现金附注](https://static.cninfo.com.cn/finalpage/2026-09-24/1225581517.PDF#page=102)

同一现金租金口径如今覆盖2020—2025六个完整财年。经营现金租赁从2020年的40.027百万元开始，逐年为88.126、72.512、175.516、424.926和1284.337百万元。融资现金租赁对应为147.995、220.126、323.041、384.999、505.104和608.288百万元。两个序列相加是各年已经公开的租赁现金总支出，不能以会计租赁负债期末远期金额填进去。既有年报对读及版本表逐行保存物理页和原表列，不兼容时保留当年原版与下一年比较列。2022年的使用权折旧原版335.630百万元，2023年报比较列为330.124，未查到使两者完全等价的解释。采用原版时现金租赁核心率约11.193%，用后列约11.073%。尤其在压力年份，不宜把这一点差异解释为真实承租场所支出变化。

以原版可复算口径，2020至2025年现金租赁核心利润率分别27.158%、24.380%、11.193%、17.868%、31.374%和45.665%。历史考验的功能在于看出固定租金和渠道费用在少增收时占多少，给利润率和终值提供范围。2024及2025高毛利后的盈利率远离2022压力，说明高销售兑现能摊薄固定店网。2026半年回到40.89%仍然不低，却比2025半年低。租赁费总支付增加约514.4百万元、同期毛利还在上涨，现金口径下降在出现正式披露的首个衔接期是有现实金额的。估值模型走向稳态时，要保住向公司收费的场租成本，稳定净率24.626%体现收缩又可持续。若未来租金与收入比更高，终值现金自然向压力阶段移动。

## 报表经营现金和FCFF各担一部分解释

在报表经营现金流中，经营租赁支付已经计入，因此若取CFO再扣资本购建只需补扣融资归类的租赁现金。2025上半年CFO5977.473百万元，减含固定资产和无形资产的现金购建374.523，减融资租金263.592，余5339.358。2026上半年3637.324减724.139减502.889，余2410.296。两期相差2929.062，约减54.86%。经营现金实际已经少2340.149，购建多349.616，融资租赁多239.297。用代码从原列复算可对各期差额逐项闭合。已知当期实付税从1189.6百万元左右抬到3219.7百万元左右，现金尚受库存、供应商支付、客户预收和税款兑现不同步的影响。同比可以说明真实可用现金下降，不能把现金缩量全部归给某个IP退热。

2020—2025历年CFO扣现金购建与融资租赁可比结余分别331.771、225.223、220.358、1213.131、3932.426和9085.327百万元。第一阶段扩张的营收跳增未使这一结余马上增加；2022年的利润明显下降，按此序列现金接近前期低位；2023到2025的恢复是多期间可见的现金量级改善。最后一年购建1171.537百万元、融资归类租赁608.288，对用年报CFO10865.152直接计算9,085.327。若把经营租赁1284.337再从这个数扣，会把新的现金释放低估。若只用会计折旧作维护资产投入又忽略最新门店与仓储的实际付款，会高估可售期经营余量。

独立FCFF桥采用现金租赁核心EBIT为起点，对其施以常态25%的经营税代理，获取NOPAT。再加不含已处理使用权租赁的PPE折旧和无形摊销，扣现金购建与可见经营性营运资本变化。从2025年年报对读期末贸易应收921.240、存货5472.839、贸易应付1858.216、合同负债393.119百万元，公式应收加存货减应付减合同负债，得4142.744。比较2024末约803.6，增加约3339.1百万元。2025补出的非使用权折旧摊销为525.252百万元。固定现金租赁口径下正常经营利润与时间匹配的税率得到FCFF代理8727.552百万元，和已扣融资租金及购建的报表CFO代理9085.327相差约357.775。原表未细分的人事、非贸易应收、存货和减值、税率或付款实践不可随意给差额贴上一次性标签。保留残差比把两式强行做成相同结果更能复核现金。

期末余额同期间区别很大。2026上半年贸易应收627.306、存货6101.530、贸易应付905.150和合同负债513.419百万元，算贸易WC约5310.267。2025上半年对照约762.390。两年同一期末差额4547.877说明新阶段存货占用较重，但当半年营运资本变化必须用2025年底的4142.744作为2026期初，因此可识别变化1167.523。若用前者当当期现金消耗，模型历史CFO残差会多约3380.35百万元，等于误把多季度资金占用放进一次半年。贸易应收下降、应付下降与库存扩大在模型各处方向不同；合同负债收款也不能继续提前认作收入。按同口径同比现金额验证正常销售结算时，首先追踪这四行是否因贸易季节、清仓折扣或买货支付改变。

## 库存的金额、现金和回报

周转用半年销货成本乘二后除期初期末平均库存。2026半年从2025年度末库存5472.839百万元和2026半年末6101.530之间取均值5787.1845，半年销货成本5207.181，年化周转约1.7996次。上一同期周转约4.33次。周转反映销货成本兑现和库存规模共同变化，降到1.80不直接说明出售件数同比更少。某些代表高价值新货，另一些可能还未上架，库存表里的减值也只说明部分资产回收金额被重新评估。第三季度未审计销售同比下降让慢周转风险上升。若更强证据表明入库仅为确定需求的提前发货、成本未低价确认，压力才有机会提早解除。估值试将周转放在1.2、当前1.80、约2.5次等条件上，金额边界必须与相同销量和毛利假设一组输出。

可识别资本子集由经营贸易资本与可识别运营资产组成。2025期末5768.965百万元，2024约1678.3百万元，资本利用效率在爆款年大幅提高。2025年公司以现金租赁对齐的NOPAT除两年平均窄资本计算约341.41%存量收益，以相邻年份税后利润增量除资本增量得约235.79%的新增回报。两者单位百分比，不能把一件商品的财务回报当343元，也不能将现有无定形故事价值纳入分母后直接与别公司重估。高回报同期集中收入放量，租赁已经通过现金费用确认而不把使用权资产再次计入狭窄的资本，欠缺业务层资本分配。2022比较窗口负增量、之后暴增，给现金模型提供成熟阶段的显著均值回归约束，采用稳定新增回报17%远低于年度观察。用增长2.2%除17%，约需保留12.94%的税后核心经营利润用于长期增长。

资本开支的支付先后决定盈利什么时候转正。门店可以先签租约开始装修支付，部分使用权账面认列不需要立即付全租金，开店后初始货架和员工需要钱。产品上市初期只有库存占用，同时商场或电商的发货、退货及平台结算还没到，账上收益与现金往往先后。对一批店和一款商品而言，准确的回款模型需逐时点配对装修付款、可售期内销售、渠道分成和退货、补货再付及租赁。现有公开原件能看集团支出和金额方向，无法直接计算某批门店或IP的资本盈亏。因此稳定回报用各年现金转化给上、下范围，新增项目具体效果留下一次可取的店龄披露再加。若逾期库龄仍增长，用折扣提销售换现金收回，需要将可能增加的销量与毛利下推到同一个月或财年再判断是否改善。

## 经营租赁口径留给股东哪部分金钱

泡泡玛特的企业价值由未来经营活动的税后自由现金流决定，包含维持租约所需实际经营付现。用融资口径统计费用和租赁债务时结果要一致，本模型未再扣经营处理的租赁债务。权益桥保留超出工作现金需求的现金、合格投资、金融债务和非归属普通股东的权益减项。基准企业价值178608.5301百万元人民币，普通股权益189516.3919，净桥10907.8618百万元。在集团结算货币中完成估值后，除以13.27969203亿经济股数，约142.85元人民币每股，再除0.85633，约166.65港元。模型的最低工作现金估计和短长投资变现金由源模型保留，一旦库存与租金超过当时容量常态，要检查工作现金准备而非用大额持有现金假定资产无摩擦。

期后回购的影响看买回成本与减少的经济股数。11月12日16:48才披露的460,000股未落当日收盘权利，之后附有更多金额及时间的回购。对任何一笔给定回购，先从现金权益扣支付，再从股份减已回购或依口径注销股数。若回购价低于原普通股内在价值，该机械效应对剩余每股可正，反之可负，均须绑定当时资料。将新回购买少后的股数倒灌回估值日则在信息截点上出错。识别经营价值是否真的改善，要回到同口径销售、现金租金与库存的联立条件，单个权益事件只能作为增量变动的跟踪。
