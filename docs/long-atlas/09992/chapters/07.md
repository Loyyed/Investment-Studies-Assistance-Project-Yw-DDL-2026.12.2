# 需要哪三个数，才能接受新的证券判断

## 用第四季度收入反推发售与门店兑现

第三季公告遵循其编制范围，首先只有未审计同比下降区间。2025全年37,120.052百万元人民币减上半年13,876.276，给下半年23243.776百万元。如果将上一年第三季度假设为半年收入50%，则用半年金额乘一半再乘50%到55%，得到本年第三季度5,810.944到6,392.038百万元。这次计算可同时在年报、上年中报和2026第三季度公告用原表单位复核。2025年第三季度的半年权重单独未知，不能拿今年秋季销售和上年全部上新周期平均同义使用。将第三季度落在35%、50%和65%三个半年度权重，可以检查季节分配如何影响第四季度的代回。权重变动不利于声称一个隐含单季额已经得到原件证实。

基准2026全年收入29492.122百万元减上半年17172.921，给下半年剩余12319.201。按上述50%权重情景，第四季度需要5927.163至6508.257百万元，约59.27至65.08亿元。区间较低端对应第三季度相对上年少45%，为使半年金额固定，第四季度不需要补更多。区间高端对应第三季度少50%，因而需第四季度补更多。相同计算可回代到阶段15更高销售实现路径，从而看到为何旧预测在弱三季度后把更大任务推给第四季度。这样推算只解决每条路径的分季算术。哪条第四季有足够利润，需要下一步对所销售商品、租赁和库存排查。

以价格143.40港元反解时，用2025下半年为比例基数，扫描2026下半年实现比例0.25–0.85，按根的结果把该半年金额减去同组季节与同比区间推得的三季度额。固定基准假设、库存周转约1.7996次、租赁指数1、额外毛利冲击为零，价根约在H2基数的36.5182%。这个根需要的H2营收约8488.201百万元，减隐含Q3后得2096.163–2677.257百万元的Q4门槛。若将长期营业毛利减1.5个百分点，要求H2基数比例约42.6764%，对应四季度3527.562–4108.656百万元。毛利额外减3点时需5130.887–5711.981百万元。条件收入明显大于后一组要求，只有同期库存和租金没有更加恶化才能说明基准已覆盖市场要求。将折扣冲击作用于较长预测比只作用于一季使估值对这种变化更敏感，因为利润率损失进入后续现金及终值。

现金租金的条件也可量化。在无额外毛利冲击、同一季节及同比少45%的分位，若周转维持约1.80次，租赁指数0.85、1.00及1.15分别要求约958.303、2096.163、3285.628百万元第四季度收入。固定合同及维护开支愈多，同样的季节恢复需要更多以正常毛利实现的销售。比较设周转1.35次时，这组上升到1046.675、2343.624、3563.823百万元。周转变差同时租赁偏高时，跨过现价的收入提高约1467.66百万元，基准假设不再代表这一收支组合。反之提高周转至2.20次未必使每项单独根都更低，模型存在正常化营运资本底线，回收至底线后的信用与库存不能用同一比例无限加值。批量变现可能有折扣，需将现金释放和毛利下移合并进入一行网格方可讨论。

求解边界也需要来源。模型在H2实现区间下从低到高扫描，同一租金指数1、周转1.80、毛利额外0的两个边界价格约127.126和211.822港元，覆盖143.40。网格合计216个组合，193个在考察Q4非负后可以等值回代，23个条件的代数根要求Q4为负，实物销售的非负约束下没有等值解。例子为周转1.35、租赁指数0.85、毛利额外0、上年Q3占半年65%、本年同比少45%。其代数价根对应第四季度负870.936百万元，表示同组在给定经营假设下，估计三季度收入已经超过使证券恰好等于现价所需的半年规模。实际决策应比较允许最小Q4为零时的条件价值及离价差，不能把负收入填零后仍标“等于现价”。若未来压力越过网格上边界，则没有依该条件能达到143.40，报告两端与价格差。

## 最强反方如何在经营数据里出现

反方可以接受泡泡玛特做出了新的有影响力产品，仍认为零售利润未足够持续。它的证据从两头来。第一，星星人的增长占2026H1收入增量近七成，剔除两个畅销角色后其余收入上行约16.09%，表明更广供给有增长但是比旺季原扩张叙事小得多。第二，现金租金核心率与去掉融资类租金及购建后的报表现金下行，时间上又出现三季度大幅同比下滑。租约本身延迟调整，整体库存约1.80次周转。若当时热门款退得快、供应商所需支付较早、老店日常销售不能接上，同样数量的新店只是增加销售固定成本，不会立即带动自由现金。估值已给现金出租条件较高的经营回报，这类证据若连成一段，模型便会由基准高于现价转到下方。

最能区别替代机制的是成熟店按地区跨两个发行期与正常日的实际经营。取相同实际营业天数、不包含开年装修的新关闭门店，比较同品类正常价售出件数、折扣和退货后净销售、所在租赁实际支付、门店出售的库存与关停转移。若排除促销和新角色超额发售，匹配同样的核心旧款新品，成熟店还能覆盖自己的固定租金与员工支出，能证明店网留存不完全靠角色冲击。若成熟店只在发售日客流高、其余周销售贡献低于同期租金涨幅，现金折价应进入持续经营利润率而不只降一次近端销售。已有集团及地区资料可以确定避免低估过热的强压力，缺成熟店销售和退换货不宜给同客户复购精确率。

跟踪库存要证明实付与资产回收闭合。若2026年年报显示年末存货下降，先看这是否通过经营成本出售，或利用减值压低账面。若通过折价销售，确认折扣导致的毛利百分比损失是否落在1.5或3.0个百分点的可翻转阈值，同时依原价和折扣变化更新显示年度报告的量价、正常下一年利润率。若退回给工厂并减少付款，库存、预付款、应付和业务合同可配合解释。若只是分店关停后把货转线上，实际集团存货未必下降。现金收回更重要的同期间口径是销售现金、经营租金、融资租金、本期资本购建与实付税一起跑，避免上一期积累的应付在下一期结清被错作当前商品的价格损失。

地域分化要求继续使用两组真正分开的验证。对国内，三季度披露线下相对稳而线上低约45%–50%，如果四季度收入恢复由网上一款商品带动但成熟店普通商品较弱，应改变特定渠道实现率而非提高门店资本回报。对海外，应比较实体增长是否继续覆盖线上下滑及地区营业费用。上半年海外实体上升5.20亿元、线上下降11.27亿元，如果实体恢复带来高房租和更慢库存，净贡献未必上升。若实体和线上都在不同发行期取得正价复购，海外经营可改善普通股价值，但应提取当地货币和时期，区域之间的增长才可靠可比。最早能核对的是下一次正式地区、渠道和分角色收入矩阵，再结合店龄与实付租约资料。

实际投资决定还取决于持有人是否接受远于短期公开证据的一组风险。模型并未为任何个人做成已成交操作。研究判定基准高于价格，条件如后续件数和实际租金验证后满足现价，需要签入新证据并全量重新生成。若第四季度的收入超过26.77亿元、且同期毛利未发生额外结构性压缩、现金租约在基准与周转率1.80次附近，按50%季节图已越过143.40。若折扣足以让持续毛利少1.5点，就必须对照35.28–41.09亿元新门槛，不能在营收超过旧线后直接判断便宜。若在基准市场难辨识具体季度金额，应将公告区间逐步收窄；缺项留过收盘快照而不臆造现金。一旦同一期披露能覆盖两项经营变量，便可缩小第三个变量的取值范围，重新量化同组自由现金。

## 期后跟踪只检验当时的看法

原快照使用2026年11月12日港交所16:10这一当地截点。估值日16:48另行发布、公告日后才取得的回购不进入原分母，期后若看股东权益价值，分别按照实际现金和已回购股份变动记账。初轮跟踪六份公告共买回2,390,000股，现金支出342,472,620港元，表内保留每条公告的时间和证券状态。两额相除，平均支付约143.29港元每股。机械比较时，若用166.65港元模型值并在后续时点以相同经营假定和汇率开始，约23港元乘239万股为回购带来的股东间权益差，再除剩余经济股份，量级仅约0.04港元。因为实际是否注销和其余变化需分项确认，算术是沿用原经营假设的回购敏感性。

回购买到较低价格，无法证实同一时期经营好于预期。以现金减少一美元或港元和相应股数减少合并，能看到回购对剩余股东经济效应较季度销售根小得多。回购公告可能与管理层认为价值较高有关，也可能只是既定资本配置方案的一部分。研究者应沿已发生现金和证券登记恢复事件，不从减股就推需求复苏。若后续确有大规模开店、租赁或货款，留可供经营的最低金融现金又发生变化，应在下一估值日先重新识别可分配现金，而不只根据账户历史余额替期后投资者增加一份同样权利。任何版本更新都保存原事件的公开日、版本和取得日，保证证券历史账与商业历史连续。

项目成员若在财报发布后补可得证据，应按来源任务分开。先由财报复核用同一口径的年报、半年收入差验证H2，确认2025Q3与2026Q3有无发行人绝对额。若有就替换季节条件并保留原版推算，如果没有就公布H2与全年可确定的区间。其次对同一期附注分别敲实付租赁、正常与减值库存、现金购建及经营税，计算同口径现金利润与实际回款。有权读临时公告的成员按时点核回购及注销，不把该事件变成年报销量。国内外门店分组若得公司公开答复，则核样本数量、营业期和是否包含开店首发。主要参数还未能缩估时，用三条已公开路径报告所有区间，给未来研究对象选择和后续40页正文明确的可继承章节。

现价的关键最终可以写成一个经营要求。消费者持续支付足够的正常价格，成熟渠道消化库存的速度能支付保留门店的现金租赁，并且前两者合力让股东未来持有约166.65港元的条件价值，143.40港元已留一段销量和支付缓冲。这个主张的最强反证，是上半年某款星星人催出的量在三季整体下跌后无法持续，成熟店只能靠折扣现金清货而租约不降。查证时先取第四季度营收填对季节，再用现金租和原价／折让成交检验正端，最后以1.80次周转附近的真实去化验证资金。这个过程能把购买理由、渠道抬高的固定成本和企业最后有多少现金连在同一张底表，给出下一次证券判断可精确改变的一个节点。
