# 谁在买新品，哪里留下毛利

## 同一份收入按角色与渠道分别拆开

2026年中报适合作为解析多组收入的截面。集团人民币口径的合并收入由13876.276百万元变成17172.921百万元，增加3296.645百万元。物理第26页按角色和授权类型披露本期与比较期，单位人民币千元。先用同一份中报原列复算，THE MONSTERS由4,814,017千元降为4,454,361千元，少359,656千元。星星人从389,363千元到2,649,969千元，多2,260,606千元。后一角色占合并增量约68.57%。两项相抵多1,900,950千元。余下其他产品增加1,395,695千元。将这两组拆开，可以检查“有新角色接续”与“整个产品组合增长”的两件事，把前者留给发行计划的验证，把后者留给渠道和组合的预测。 [泡泡玛特2026年中报物理第26页](https://static.cninfo.com.cn/finalpage/2026-09-24/1225581517.PDF#page=26)

按余下基数计算，2025上半年集团扣THE MONSTERS收入9062.259百万元，2026上半年扣除后12718.560百万元，同比增长约40.3465%。若再扣星星人，比较期8672.896、本期10068.591百万元，同比增长约16.0926%。同一家公司内部的两个口径一个证明不止原头部销售，一个减少新头部大额上升的基数影响。计算不能从两条增速中做简单差值当某类销售增长，分母不一样。若估值用16.09%支持组合持续增长，还要分析这段包含开店数和地区收入增长，无法说明老顾客的复购概率。这项核查提供作为量／组合输入的范围出发点，后续较弱三季度并存，不把集团旧头部减少自动分配给任何一地。

地区按中国、亚太不含中国、美洲、欧洲及其他四划。对各地只加零售门店、机器店、线上、批发及其他四行，若再加线下小计则会重复实体和机器。中国渠道由2025上半年各行合计8282.812到2026上半年12200.509百万元，净增加3917.697百万元。零售店增1683.738，机器店增100.655，线上增1841.491，批发其他增291.813。四项与中国合计闭合。海外净减少621.052，而海外零售店三地绝对额分别增加223.180、166.102及130.956百万元，合增520.238。海外线上分别减少425.663、604.421及97.332百万元，合计减少1127.416。剩下机器及批发混合约负13.874百万元，最终与海外净变动闭合。数字支持优先改海外线上销售实现和基数，不能用总增长23.76%把任何地区线上都推上同期高增长。

地区与角色两种划法还容易误读同一笔交易。某角色玩具在中国门店收款，既在该角色IP表，又落中国零售渠道。算集团销售增长只选其一作为分组桥；若做归因模型，可交叉作为数据维度而非可加项。报告在2026上半年没有同三季公告交叉披露同SKU及门店、线上结算。现有数据不能回答海外线上减少的1127.416百万元里头部IP占多少，也不能算国内门店净额来自多少个不同IP。要拆成销量、价格、组合，必须知道同规格产品的销售数量和扣折扣实现价，组合桥需相同销售范围。现有原件只允许从收入贡献和店网变化给出代理，产品、地区和渠道彼此重叠时保留不可分拆残差。

第三季度披露让同一组渠道表延伸到不同空间。2026年10月27日自愿更新按初步管理账披露未审计集团收入同比下降45%—50%。中国下降25%—30%，中国以外亚太下降65%—70%，美洲下降70%—75%，欧洲及其他下降50%—55%。中国按渠道线下下降5%—10%，线上下降45%—50%。集团、四个地域及国内两个渠道出现在一份公告，合计七条为各自比较期的比例区间，不是按某个中点统一汇总的交易表。加权应有2025三季度各行绝对额作分母，且中国地区线下和线上属于子层级，不能与多地各行加重复。期间未审计也只描述收入侧，没有同时更新现金、净利或库存。相较上半年国内线上增长，三季度相同比例说明发行节奏、市场范围与库存去化可能正在改变；估国内外四季度各渠道的实现率时需吸收这条证据。 [2026年10月27日公司经营更新](https://prod-out-res.popmart.com/cms/LATEST_BUSINESS_UPDATE_FOR_THE_THIRD_QUARTER_OF_2026_c437e22e46.pdf#page=1)

## 门店增长能回答多大范围

2025上半年中国零售门店由期初431至期末443家，简单均值437。2026上半年从445至455，均值450。两期间中国零售门店总收入分别4405.948与6089.686百万元，除以平均门店数，得到约10.08与13.53百万元每半年度均店代理。只有在所有开店时间或关闭时间较均匀，且渠道和地理统计口径一致时该近似才可解读。它无法剔除新增旗舰店、城市位置差、以新客为主的热销首发、同店可售天数和门店尺寸。亚洲及海外门店平均收现不能用中国网络的同样结果推断。报告提供门店层比较的最低必要资料，也缺恰好决定留客和固定经营收益的店龄分层。

可以做不需要同店妄猜的拆分。把同比两期店数平均变化代入同一段网络零售额，令旧平均每店半年度销售约10.08百万元，按额外13家估规模贡献约131.07百万元。剩余约1552.67百万元反映既有与新店的效率变化、不同开业时点、货品位置和组合。在应用相同中点方式时，会把新店对平均店效提高的交互分一半给数量；与固定老店均值的分配给出不同归因，但都不等于成熟店同店。更强的检验要从2025开业前的一批门店选取全年可比营业天数，排除搬迁、休业、快闪和首发活动，按金额、件数和折让重复估计。若真实成熟店持续增长超过网络代理中的大部分，门店开张带来的资本和销售弹性可以被单独重估。

由公开信息能证实欧洲和其他地区实体卖得更多，也不能说明单个租约有盈利。若在新进入城市花更高租金和员工培训使实体巨额销量增长，集团分区销售仍未检查对股东的贡献。与此同时，物流成本、线上平台佣金和发货品类配比可能下降或增长，实体和线上的经济对比须按实际地区结算。地区均价还会被外汇、同一商品售标和渠道折扣影响，不能借人民币收入变化直接判当地成交件数。模型把这些未识别因素放入实现和组合路径，不把本地报表的海外线上收入变化解成单店减少。

## 每一百元销售额下一步流向什么

在集团功能费用表，2025上半年可比收入13876.276、销售成本4115.212、毛利9761.064百万元，毛利率约70.34%。2026上半年收入17172.921、成本5207.181、毛利11965.740，毛利率约69.68%。毛利多2204.676百万元，成本随收入扩大且单位收入的成本略高。销售费用由3192.590至3931.123，管理由770.405至926.526。毛利扣这两项，分别为5798.069和7108.091百万元，核心EBIT增加1310.022。报表营业利润从6043.741到6724.746，增量681.005。核心差别由其他收益、费用和报表调整闭合。旧期报表较核心高245.672，新期低383.345，须保存原符号和各列的详细科目，不能把约629百万元差向全部赋给商品毛利。租赁现金口径另加回会计租赁性质，不能将现金替换当作剔除某个一次性损失。

中报费用按性质给出可辨识变动，入销货成本存货由3272.871到4303.215百万元，多1030.344。员工多412.340，用在销售端和其他功能。运送物流少30.321，电商佣金服务少80.490，授权费用少74.924。使用权折旧多197.750，物业及设备折旧多124.420，体现网络更大或折旧结构变化。短租及变量会计租金多159.789，营销增加43.174，存货减值多18.504百万元。费用性质与利润表的销售成本、销售费和管理费交叉，只在拆相同功能总项时对读，绝不能从毛利再扣一轮入成本存货、物流和员工。按性质能看到履约开支的相对方向，短租、折旧和租赁付款要在下一章形成同一现金识别口径。

成本变化与实际定价还可设条件辨识。若组合不变，毛利率随直接制造和授权成本变化才反映生产规模。若商品公司趁新客潮加大促销，发票净价下降且每件成本不动，确认的销售成本相对收入提高。同期授权费用下降、存货成本增加，无法同时解出商品售出量与每件支付多少授权费。观测层可确认集团可比毛利率下降约0.66个百分点、销售费用率基本相近、现金租金核心利润率下降约1.40个百分点，给超额折扣成本的范围定位。要说某地区加码折扣，应由同SKU实际成交与优惠数据、退货率和结算期证明。报表已计存货减值和实际清货发生在不同时间，清货现金可能提升周转而当期损失权重更高。

对新渠道的具体开店条件，可以用单店现金平衡检验。令店铺不含税净收入为销售件数乘扣折扣均价，按真实商品及供货运输成本得到毛利。减区域门店薪资、变量平台和履约费、退换货、面积租金、维护购建和增加的库存或应收，计算新增经营现金。装修现金应按发生时点纳入，开业相关宣传不得当作永续费用又当作资本扣重。区域仓配同时服务多渠道，通常要看实际物流占用结合新增箱次分配，不能用集团费率等价地摊给每家店。若期内寿命或押金能够实现，释放的现金也应在关店日而非所有营业日同时实现。公开报表只识别跨期资本和现金租赁，故不宣称存在直接单店盈利结论，下一步把这些条件以全国成熟店的公开销售或附注缩小区间。

在现金约束并入估值时，折扣、租金和去库须联立。单价下调使收入和毛利同向变，若促销足以加速旧货售出，则资产端回收能够部分抵销。反过来，暂时缩减采购可以减少营运支出，却有可售品缺货、商品过时或运营租金覆盖下降风险。用整体毛利每降1.5个百分点作为可重复折扣压力的情景，会在冻结成本税率、长期增速和折旧条件不同阶段作用，不能只从当季收入直接算股价。若有限期内用货架变空换到暂时周转，成熟期不应把一次性收益重复计算。更新销售实现参数应优先取分品类或地区的正常成交，拿不到就保留条件盈利和现金流上下界。

进一步审查余下增长是不是碰巧由第三个角色独占，可按中报第二层分类逐行取算术。CRYBABY增加414.400百万元人民币、DIMOO增514.082、SKULLPANDA增330.707、HIRONO增280.435，原表其他艺术家IP反减少10.138。MOLLY少456.617，Zsiga增加87.085。去掉两个头部后，其余艺术家IP这些增减合为1159.954百万元。再加授权IP增加246.359和外采及其他减少10.618，独立加总与剔除两头部后的整体增长一致到舍入范围。报表同一份中期的艺术家IP小计是两年可对读的母行，逐行加总时不把其与子行放在一起。剔除双头部的总体增长既有多组正贡献，也有一个成熟名字减少超过四亿元，使“每个IP都随客群扩大”可被否证。替代力本身是组合分散降低单发的暴露，要预测近期有效销售，还得知道这几款增长在正常购买月份和线上线下分别留得住多少。 [2026年中报分角色收入及版本镜像](https://static.cninfo.com.cn/finalpage/2026-09-24/1225581517.PDF#page=26)
