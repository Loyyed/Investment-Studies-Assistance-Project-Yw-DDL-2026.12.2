# 要有多少经营资本，才能留下多少股东现金

## 从营业利润走到现金

估算经营价值先把人民币普通股的两种收益分开。客户支付的设备订单和后续服务属于持续经营。多余货币资金、理财和其他投资给股东提供另一项金融权益。公司收到现金并不单凭收入确认形式区分这两项。账面公司利润的行政科目将利息、投资收益、公允价值变动等放在营业利润内，所以不能用营业利润直接代表设备经营的利税前利润。分析口径剔去有对应金融资产的回报、非持续其他收支，并保留营业正常所需的研发、销售、管理等费用。金融收益再由金融资产的可得性、最低运营现金和剩余现金权益反映，避免两个收益口径穿插。

审批一条季度桥时，先在列头确认当期为累计。2026前三季营业利润1226.03103942百万元，核心EBIT938.19389727百万元，报表比核心高287.83714215百万元。此前一年的同列为1030.23951791和884.21853025，差146.02098766百万元。年度累计比较显示营业利润多约195.79百万元，核心多约53.98百万元。报告增长中很大一段来自核心外占比提升，具体分量逐条使用原财务费用、其他收益、投资收益、公允价值、信用及资产减值和处置，有利有弊项目按原符号相抵。有一点别被两种经营率混淆，审查者从毛利向下独立相减到相同核心利润，表明该期间大幅营业利润增长确实不能全部估作经营表现。

经营现金税在模型以明确代理计算。基准路径采用13%税率，把现金税与核心营业利润对应，以剔除金融收益税影响。历史上2025年分析EBIT1042.70684855百万元乘以87%，得到约907.15495824百万元代理NOPAT。这个数也用于窄资本历史桥，税费附注原缴金额如不能按主业和投资分开，不能写成税务局收到的实缴。税惠政策资格、亏损抵扣、递延确认和投资收入税法均可能改变实际缴税，但只有哪些现金税确实对应经营要素才影响FCFF。2025年毛利和研究费用对账与现金税的处理同样重要，若直接拿征管口径税率乘报告营业利润，NOPAT把投资收益改成税后经营额估值，企业价值和权益桥都会被放大。

把代理NOPAT转成FCFF，以经营可见的折旧摊销、现金资本开支、贸易营运资本变动和租赁现金联立。2025年代理NOPAT907.155，折旧摊销37.355，已辨识贸易营运资本增加89.489，现金购建35.203，合起来在其他租赁、现金异常和科目残余前约819.817百万元。报表CFO1104.321，扣现金购建1069.118，与前一量约相差249.300百万元。直接将差额归为处置收益或服务支出均无证据。经营现金报表还可含相关政府款、税收时点、未纳入子集的经营余额、应收票据和正常非购建差异。购建与营运资本的方向清楚，较大的剩余要求把整个对账过程和已知范围保留。集团CFO不是模型税后核心现金，做比较时使用计算方向和解释力，不强行降低残差。

2024年的对应算术为代理NOPAT748.226，加折旧摊销31.286，扣贸易营运资本变动44.545与现金购建113.218，得621.749百万元。扣购建后CFO839.225百万元。跨期桥显示这一年投资现金偏大，第二年年购建缓下来使同一经营利润可留现金增加。2024和2025间，代理NOPAT约增158.93百万元，已识别折旧增加6.07百万元，贸易营运资本多增加44.94百万元，购建现金少付78.01百万元。已识别FCFF改善约198.07百万元。要在下一年重复这一收益不能假设购建可再次大幅下降。如果方案更多涉及硬件，人员、实验与存货沉淀仍持续，需要新的建设与设备计划给出年均维护现金。

## 把库存、周转与项目支出分开

产量、销量、库存三行用于定位供货节拍。系统生产量67,434套，高于销出65,064套，两者不能直接核作期末库存增加2370套，因为库存口径也涉及套件、备件、退换货、单位校正以及在途期间。硬件销售更快，意味着集成可以吞并以前属于其他供应方的收入，也让公司的采购与库存更广。这类机会对集团层利润的方向可以由分部毛利和收入解读，对营运资本的方向则需看同一季节、同口径的集团余额与成本。2026年而非全年计算的期末存货天数约216.33天，上年同日约166.37。若不足以分别获到对应金额和平均余额，只能称年化期末代理。用同季期末库存除累计营业成本再乘以相应会计日数，可识别变化，单日现金付款和成本构成仍不同。

期末有量的商品可被卖出，资本仍受信用期和保修义务限制。销货当天将存货转为应收不等于收现。如果重要设备客户获得较长期限，则营运资本在两种形态之间转换。考虑公司同时提高应付供应商，会使账面营运资本少于实际需要的最低现金准备。绝对占款也受订单中途付款与制造工具的押金内外范围影响。扩张若由高性能成套方案拉动，表中建议保守保留库存和应收共计的交易子集，而不是将维护的经营资本随新增配套率下降。归因更强的证据是相同合同的在制品、发货、收款及返修在同一期间闭合。

新增资本可能已经投、但未能产生新增销售。智能切割头募投原计划投入约218.40百万元，到项目调整和结项公告可核的累计投入约18.41百万元，比例约8.43%。结项和优化配置于2026年1月16日已有公开记录，口径并未声称原计划建设水平已经实际完工。如果估值以剩余计划额直接当未来定要付的款，就忽略已经调整的项目和用途。反过来，以花费较少认定单线现金超预期也无依据。回报测定需看新增产能与原产能替代比例、合格部件数量、单位外采节省、实际保修现金和增量备货。项目资本减少和贸易资本增长可并存，集团资本开支加减并不能决定项目现金回报。

取历史窄投资资本对应资本周转，可见2021年2.80倍、2022年1.90倍、2024年约2.27倍、2025年约2.58倍。各值由全年收入除以期初期末窄资本平均值。2025年存量ROIC代理约106.54%，以代理NOPAT907.15除以两年资本平均。同期新增回报约194.14%，用约158.93的NOPAT增量除约81.86的窄资本增量。当新增资本很少而业务密度上升，新增回报极高，也对资本界定敏感。研发已经作为期间费用减现金，历史资本未将工艺知识存量显现。忽略研发资本化仍可比较同口径年度，不能与资本化开发的公司直接比较投资回报。2022年增量回报为负，说明匹配当前投入与当前经营收益也可能把时滞误认作永久经济性恶化。

估值采用经过成熟过渡的新增回报23.5%。2025年的直接窄增量超过这个数很多，同样的历史不能独立证明终值可以用194%。成熟期的参数反映继续获得新订单时付出的产品迭代、售后及资本，而非只用老平台处理现有系统。历史里2022年亏于增量、2025年成功摊薄资本表明参数应针对相似业务阶段取一条在经营条件上可观察的约束。2.3%永续增长除23.5%新增回报，对应约9.79%的税后营业利润必须再投资。若稳定增长相同而实际所需资本周转更慢，新增回报降低，留给投资者的自由现金流随之减少。把短期库存去化形成的现金释放永久计入终值，会使承诺再投资与增长条件无法匹配。

## 股东拿到的是经营价值加权益，减去自己的义务

同日权益桥从经营价值32433.981274001948百万元出发。估算可供股东分配的金融资产以账面金融现金2134.54113072加符合口径的短长投3596.03113218，再扣400百万元最低经营现金，得到5330.57226290百万元。再扣金融债务20.322、融资处理的租赁8.67711065与少数股东扣除77.3536。净桥5224.21955225，加经营价值到37658.20082625百万元。按同日经济股数4.05984426亿除后约92.757747元。少数股东账面48.346是另行扣除的参考，扣除值用其权益价值代理表达集团合并现金流有非母公司份额，一张表里不能再用少数股东账面额扣第二次。融资型租赁留在承担权益风险一侧，经营租赁在FCFF扣现金，仍须核两组范围不能重叠。

股数根据10月28日归属登记，从6月基数405,557,343股增427,083股，至405,984,426股。把此前股本加入归属后利润再分给更多股东会更准确。若有其他潜在股权稀释，需要以可获日判断是否满足归属与可行权。未来分红是从公司现金转到股东现金的路径，持有证券权利不允许在分派之后仍把被支付金额留在企业估值。11月16日实施除息与11月12日市场锚分开登记，机械调整每股约0.582元，实际成交变化不能由机械数本身推导。这种时间隔离使除息后的观察能核股价和实收，同时保留原版同日对照。

以控股股东看见的全部现金衡量回报需要各看一次三个指标。已发布CFO说明报表内现金流实际去了哪里。分析FCFF将长期经营税、资本开支、营运资本和租赁调至与DCF同口径。投资现金和股东分配通过权益桥表达。若三者之间出现跳变，第一问回款提前或资金管理改变，第二问未来经营现金是否随之变动，最后判断现价比较有没有新信息。有了这层区分，才能将下一次存货去化是释放现有现金、提高长期增量回报，还是伴随低价抛售压毛利，写到能够回代价格的方向上。
