# 收入桥里的组合变化，毛利桥里的硬件价格

## 先把主营四组闭合到合并收入

2024年与2025年年报的经营章节，以解决方案族划开主营收入和成本。以人民币百万元计，平面、管材、三维及其他主营的收入合计从1717.87493691增至2166.64476024，增加448.76982333。合并收入按同年合并利润表由1735.45507067变为2195.63231292，增加460.17724225。差额来自其他业务的收入增加约11.40741892，不能列进解决方案的价格、销量或毛利变化。其他业务由2024年的17.58013376增加到2025年的28.98755268，两数分别与本年合并利润表回勾。比较用相同四行的经营章节，附注中“其他”的范围可能包含非主营，先按原表定义判断可以合并的空缺。国内外、终端类型与解决方案有重叠，若用地区总和再加产品收入，会重复确认全部收入。

四组金额足以说明何处增长。平面增加168.09688668，管材增加107.21865315，三维增加27.11601249，其他主营增加146.33827101百万元。按主营增量为分母，四组约贡献37.5%、23.9%、6.0%和32.6%。比较集团增量时，其他业务约占2.5%。从增速看其他主营同比约83.1%，三维约73.7%，管材约28.2%，平面约14.9%。从绝对额看，仍是成熟平面方案贡献最高。投资估计依赖绝对额且必须配上净毛利，若只按最高单项增速排行，很容易把三维的少量销售假设成整体迅速上行的原因。

当期可识别控制系统销量为65,064套，比较期在2024年报物理第26页同一销售量列是60,993套，增长6.6745364%。2025年原报告物理第29页将生产、销售、库存分列，67,434是生产量，混进销售会把增长率多算近四个百分点。硬件按同一销售列从35,118到56,824。两年主营收入除以控制系统销售量分别得到约28,165和33,300元每套。这是全方案收入当量，把不附着到给定系统的硬件及其他活动也计入分子。不能由差额得出系统本体涨价。可用于合并收入桥的中点法，将套数差乘以两个单位收入当量的均值，得到约125.1127百万元销量相关归因。余下323.6572百万元是实现价与组合归因，包含可能的硬件、机型及其他未识别变化。中点分摊使交互项由两边共同承担，合计与主营变化精确闭合。

两维进一步可以检验模型方向。若2025年的全部主营增量都来自多售控制系统，按上年当量约2.82万元，约需要在上年套数基础上增加近15,934套，实际增加4,071套。把差额当涨价同样缺乏依据，因为切割头等硬件的销售量增逾六成，管材和其他主营收入份额同步抬高。最贴近资料的判断是，系统渗透继续贡献产量，方案扩展对实现和组合贡献更大。2027以后以控制量和实现／结构分立输入作情景，比用全年主营增速来训练弹性合适。相同价格组合持续并不意味着切割头组有可独立验证的反复收益，要追每一类配套的成交与保修。

## 毛利率的下移由两种机制组成

主营解决方案的四行毛利之和，由约1383.43到1688.25百万元，多304.83百万元，其主体来自平面124.16、管材78.56、三维23.14和其他主营78.96百万元。分部各自多赚钱与集团毛利率下降可同时发生。反过来，某一组毛利率回升也不意味着整个组多留出现金，若新单应收增加更快，或含每单更贵的售后与运送，现金可能在账外阶段被咬掉。先将分部自己的毛利率与收入权重的变化拆开，可以给出至少一段可跟踪的证据。

毛利率中点分解可以手算明细。对各组，以新旧收入占比差乘以新旧该组毛利率平均值，再将四项相加，得到约负1.38066个百分点的组合影响。以新旧毛利率差乘以平均收入占比，得到约负1.23060个百分点的分部内影响。合起来负2.61126个百分点，等于主营总毛利率变化。组合项里，平面本身毛利率高，其份额下降对总体的直接贡献约负4.766个百分点，其他三组份额增加产生部分反向抵消。净下降的原因是相对低毛利份额增加速度充分高，平面份额减量又大。分部内项里，平面和管材分别约负0.7184与负0.7007个百分点，小于低合约成本或高配套价格的假设。三维与其他主营内率提升，抵消约0.1884个百分点。用合并成本核出的毛利率变化略不同，主因合并范围还含其他业务。

这两项进模型的方式不同。再售同一配置的平面或管材若能提高发票净价，或工艺生产、采购单价让成本降低，影响分部内毛利率。让更重的硬件方案份额继续增加，即便每一组内部保持原毛利率，组合仍影响总毛利。未来套数扩展可能要求额外质检、耗材、返修和销售人员，影响的是毛利到经营 EBIT 的转换。把所有项统统计入“搭配率提高”一条输入，没有办法说清利润率上、下和营运资本同时变化的合理方向。针对设计集成价值，先看高配置发票和同行替代，再在集团利润桥限制该收益能够穿透至核心EBIT的上界。

以集团2025年为例，收入2195.632百万元，减成本490.538得毛利1705.094。销售费用136.844，管理155.678，研发341.330，再扣税费附加等营业科目进行核心桥。直接 1705.094－136.844－155.678－341.330 约1071.243百万元，与分析EBIT1042.707有约28.536百万元间隔，需要在列税金及其他项目后闭合。核心值从报表的营业利润剥去非核心收益计算，并接受从合并毛利减可见费用的交叉核对。2024年至2025年总毛利增长317.838，核心经营利润增长182.677百万元，约135.16百万元留在费用和其它经营损益。比较年度边际核心率约39.7%，低于两年总体核心率。若增量销售仍以相近边际率增长，把集团未来稳定核心率提高到接近50%就需要另有单价、组合或效率力量。

前三季2026年按累计利润表看，成本509.067百万元减去收入1879.567留毛利1370.499。销售89.715、管理117.213、研发203.881、税金及附加21.496。逐项相减得到938.194百万元，几乎正是核心营业利润。这条算术能与从报告营业利润1226.031百万元剥离投资相关收益的桥对读。财务费用负88.702百万元显示净金融收入，利息收入91.061百万元已作为子项包含，不能再次剔除。其他收益、投资、公允价值和减值等保留报告符号并对回报表差额。2026累计毛利率约72.92%，2025全年约77.66%，不同季节不能把五个百分点均当作结构变化。同比累计核心率下行和年报组合下移并列，支持在模型维持比历史峰值保守的现金边际。 [2026年第三季度报告物理第8–9页](https://static.cninfo.com.cn/finalpage/2026-10-27/1225622322.PDF#page=8)

出售一单硬件的边际判断不需要将集团所有费用平均摊入。需要的是有与无配套的差额，分子用含制成与运输成本后的可归属毛利。再将开拓返利、交付培训、后续保修预期、应收新增、备件新增、工具及需要持续维护的资产列出来。税率使用模型代理时，对能够抵税的费用计税影响，库存和收款依实际付款时间。在同一期间支付的可归属费用上限约等于增量毛利扣税和其他现金支出后倒算的费用余额。对每100百万元配套增量收入，如果可归属现金毛利仅有30，履约与保修消耗5，新增营运资本30，首年现金在暂未计税前已为负5百万元。假设每个量都应该从真实订单得到，数例提供反证结构，不是实际业务毛利。

产品年报能看生产量、销售量和库存量，资产负债表给金钱库存。表一范围为选列产品，表二范围为集团存货并含不同形成阶段。选择硬件销量作分母，用集团库存总额估每件占款是一种集团上下界代理，不是项目分配。要排除单纯季末出货前备料，可以先看同期金额、成本和季度同比，再看次季库存是否回落、销售回款与应收是如何变化。要排除大量硬件需售后备件，得看库存附注里原材料、半成品、成品和备件，问库存的新增是否来自保修承诺。面向切割头或三维系统的场景，实际回款时间与合同保修承诺能解释比集团库存天数多一阶的净贡献。

资金占用还受渠道不同交付、收款方式影响。对经手设备厂，它可能须先付部分材料费用，再经验收回款，再与供应商结算。回款按账款或票据来得慢，会令销售高于真正到账金额，哪怕客户未出现坏账。向海外售出的同规格配套可能有额外运送、当地维修和备件仓，支付币种转换抬高单位成本波动。给经销商备货可扩大新设备覆盖，销售若在货物已控制移交时确认，退换货和实际终端订单仍影响后续购买。渠道披露欠缺时，把这些环节放在现金覆盖上界，收入模型只计已能确认的增长，不直接将一个地区的现金利润平均赋给某个具体设备厂。

行业价格竞争也有可识别的量化表象。交付高功率方案时外采购入件价格跌得快，单台售价下降的同时毛利率可能上升。反之如果企业用更佳零件维护工艺稳定，成本下降更慢，份额增加而单台所得毛利减少。当前产品组没有单规格成交数量和报价组合的公开连表，双变量情景让销售量和成熟利润假设独立移动。走势若与归因不符，应优先重看分部内成本表、集团研发和销售，再决定是不是换成不同量价路径。在96.20元反解中，变动仅几个百分点的核心利润率已足以跨过价格，配套收入的高增长要能承受这个单位检验。

2025年主营分销售模式披露只列直销，金额2166.64476024百万元、成本478.39076146百万元，等于主营四组的收入和成本合计。原研报口中的渠道可再分到设备厂、代理或终端，年报这个“直销”却是发行人确认销售方式。设备厂直接向柏楚买系统后再整机售出，集团仍然记直销。因此既不能额外虚构经销规模，也不能用这张表径直断定所有终端用户向上市公司下采购单。渠道结论沿合同交付、后续支持和收款主体拆。地理披露提供另一侧证据，同份2025年报物理第28页华东收入1552.428百万元，占同口径主营约71.65%，本区成本325.930百万元。华中和华南458.865百万元，成本115.782百万元。这些口径可以做区域需求集中及成本对照，不能将地理集中解成前几大制造商年度续购份额。地区的产品成交与信用承诺若有公开资料，可再解释稳定核心率偏低来自什么订单。 [柏楚电子2025年年度报告](https://static.cninfo.com.cn/finalpage/2026-04-10/1225091045.PDF)

增量材料投入与其他主营更快成长支持硬件负荷上升的解释，但原料消费支出增加不是单价观测。采购时点、产品迭代、硬件规格升级及更多在库实物都可推动总额。集团实际出货跨多个产品全体，智能硬件生产59626、销售56824、期末库存7963套。对照上一份年报期末3127套，库存增4836套，而当年产量减销量等于2802套。控制系统这两种库存差也不同，7340减5226等于2114，生产减销售却为2370。年报单列库存与产销是原披露，差额未能从原表推出退货、范围或其他流转，需保留残差，不能按差额伪造备货损失。供货端的下行判断继续由集团库存及结算数据核实。 [柏楚电子2025年年报产销及成本](https://static.cninfo.com.cn/finalpage/2026-04-10/1225091045.PDF#page=29)

同一份年报物理第30–31页的前五客户销售额47,207.41万元，占总收入21.50%，第一名占6.25%，无披露关联销售。第五名是报告期新进入前五，并未揭示其是否为首次采购客户。以百分比审查客源风险，可以知道销售没有由报表一个单客户过度集中，但不能把旧前五与新前五的比率差视为老客流失。需要看客户口径按同一控制人合并，客户名称表隐去，各年行号不保证对应同一企业。对供应商的前五采购比例约25.82%，有三家新进榜，与物料组合或采购变化可相容，不能直接假设作用于保修成本。正式检验切换成本仍优先取相同机型从试用到续配订单，尚无身份公开时就以匹配的应用、期限和结算代理做有限验证。 [前五客户及供应商披露](https://static.cninfo.com.cn/finalpage/2026-04-10/1225091045.PDF#page=30)
