# 从控制系统放量到软硬配套

## 第一段：首次放量及投入先行

2019年是可连续对齐年报的起点。营业收入3.761亿元，成本0.695亿元，集团毛利3.066亿元，核心经营利润2.177亿元。毛利率在超过八成的位置，税前核心利润率约57.9%，已见到控制技术在多个应用中复用的收益。报告营业利润2.601亿元，可从约0.424亿元的差额辨识经营与金融等项目的影响。招股书可以补上市前经营段，但需保留独立口径。一个已知对照是2019年利润表列上期营业总收入2.453亿元，不能用这个报表上一年度的合并比较列代表所有产品、现金或资本项，也不宜把发行前股本对应值拼成上市后估值历史。

2020年收入增至5.708亿元，2021年再到9.134亿元。以2019年原数为底，后两个年度的同比约51.8%和60.0%，明显快于成熟设备链一次再配置。据组合研究所需，同时看营业成本由0.695亿元先到1.100亿元、再到1.800亿元，毛利率分别约81.52%、80.73%和80.29%。企业在放量时维持毛利率处于较高区间，但未出现随规模扩张连续抬高毛利率。产品组合和可能的供应链变化解释了部分幅度。以三个点为训练窗去外推出货，等于假设早期产能承接与市场开拓永远同步，往后看不住后续报表的回撤。在预测模型中把这两年用作控制方案在早期渗透中可占据很高毛利的上限证据，比把早期收入增速作为长期参数稳健。

首次放量对应研发增长和付款。2019年研发0.413亿元，2020年0.821亿元，2021年1.381亿元。若把研发视为人员薪酬、设备和工艺迭代的前置成本，对应三年研发率约11.0%、14.4%、15.1%。花费增加的同一时期也扩大销售和应收，不能将其只解释为一件成功产品的全部研发投入。收入扩大需要至少满足两个先后条件，先把工艺固化为可运行产品，再有足够机型通过适配并由设备厂确认交付。年度研发和下一年收入之间的顺序合理，但不能从任意两点算出一套功能的收益。若将2019—2021年的研发折算成长期资产，仍需指定几年的有用寿命和重复投入，现有现金口径保留费用化支出，避免凭假设改变报告和模型可比性。

扩大产销也需要筹集短期经营资本。贸易营运资本可识别项由2019年的0.394亿元升至2020年0.639亿元、2021年1.421亿元。2021年的新增占用约0.782亿元，超过2020年新增的两倍。经营现金流由2.399亿元到3.625亿元、再到4.987亿元，购建现金支出约1.133、0.449及1.635亿元，相抵后的现金分别1.266、3.176和3.353亿元。2021年收入跃升，经营活动形成的现金也多了，但当年投入又增加，扣购建后仅继续增长约0.177亿元。把这些序列放在同一张图上能看到业务更快增长并不一定同步改善所有股东可用现金。

## 第二段：需求压力把利润和回款分开

2022年收入为8.985亿元，较上年少0.149亿元。营业成本却由1.800亿元增至1.889亿元，毛利降0.239亿元至7.096亿元。销售、管理、研发分别从0.423、0.604、1.381亿元到0.472、0.748、1.436亿元。固定工程和组织人员无法随收入下调，显示年度核心成本留有刚性。以13%税代理的经营利润衡量，代理NOPAT由4.211亿元降至3.778亿元。核心率、销售费用率和资金周转结合，可将这年定为需求压力而非纯金融报表问题。任何将所有机型续购乘以确定增速的模型都要说明，为何压力年新买主、采购频率或行内售价下滑不会重现。

同年 CFO却由4.987亿元增到6.193亿元，现金购建由1.635亿元降到0.968亿元，扣购建后5.225亿元高于前年的3.353亿元。贸易营运资本子集回落0.118亿元，帮现金转换改善。经营压力不一定在当年CFO里呈同向，既有应收回收、付款条件和资本项目节奏均可带来相反方向。仅就已识别的净贸易营运资本变动和购建，前者由占用0.782亿元变为释放0.118亿元，后者少付0.667亿元，两个变化同方向贡献约1.567亿元。CFO减购建净变动约1.872亿元，剩余与利润、税金、经营其他收支及确认时点对读。把改善部分设为经营利润增长会直接与毛利和代理NOPAT相矛盾。

用收入留出做可复现反证。若估值者在2021年后仅用2019–2021年报确认的两年复合增长训练，以2021年9.134亿元基数，下一年会预测约14.24亿元，实际是8.985亿元，高估约58%。这是单一两年训练窗的诊断算术，可由三份既有年报复算，未被程序当成历史控制套数观测。错误一方面来自股票研究时常见的快速渗透外推，另一方面来自目标变量横跨产品、价格和库存交易。公司没有逐年公开统一控制套数和同配置净价的历史全序列，不能借总收入的误差解释软件数量的独立预测误差。底稿保留系统量6.6745%的直接产销观察，用留出证明不要将扩张期复合增速外推，两项证据角色分明。

资产收益同样有上下行周期。已识别资本口径在2021年约4.220亿元、2022年约5.222亿元，代理NOPAT却少约0.434亿元。日前口径算当年增量回报为约负43.3%。本年测试期也包含投入逐期形成、手头订单减少和报表期点重合。增量指标的负值足以提示如果模型把新增投入一直按很高回报计价就缺证。反向也一样，项目尚未达到交付时，负值不能证明控制系统每年都没有经济价值。应在同批系统投入、投产和订单现金的顺序更清楚后，再把峰值和谷值区分为短期产销错位还是稳定盈利能力的变化。

## 第三段：方案范围扩大，质量按净贡献检验

2023年营收14.071亿元，较2022年上行约56.6%，2024年17.355亿元，2025年21.956亿元。三年毛利约11.304、13.873、17.051亿元，研发为2.615、2.810和3.413亿元。2023年复苏与增售扩张并存，研发比率抬至约18.6%。后续扩张中2025年研发额较前期增加约0.603亿元，科研能力是否跨型号复用须靠出货、同客户复用和控制方案维保需要映证。销售费用从0.910上涨到1.014，再到1.368亿元。同期报告营业利润和核心值均上升，2025年核心率反而从49.56%降到47.49%左右，显示毛利变化、销售、研发、组织支出合并后，并非所有收入都以旧的边际率进入利润。

2024至2025年的四组表把这段增长还原到产品。平面收入11.248亿元变成12.929亿元，管材3.802增加到4.874亿元，三维0.368升至0.639亿元，其他主营1.761到3.224亿元。平面贡献绝对额最多，其他主营接近，管材增量排在中间，三维增速高但基数仍小。基准预测考虑的是成熟平面业务和复杂新方案并列。模型若把小体量增速用到整个公司，容易期望销售可以很少增加售后，就保有旧的毛利。能听到的报表信号是平面、管材毛利率仍超过八成、其他主营明显更低。行业供应链中的支付意愿在不同方案上分布不均。

持续增长能否压低单位经营费用，在2025年的现金与资本同时出现两种表象。经营现金流11.043亿元，现金购建0.352亿元，扣购建约10.691亿元。2023和2024购建分别1.515和1.132亿元，流量下降意味着当期投资强度改善，也可能反映建设和付款阶段已走过。贸易子集从2024年2.484升至2025年3.379亿元，多占0.895亿元。量的增加带来更高应收与物料配备，扣购建现金仍变好，说明需要更细的账期、库存结构和项目支出理解。下一年若备货继续抬升而现金购建无法保持低位，仅使用一次性的购建下降会放大稳态生成现金。

2026年前三季补充了新的限制。合并收入18.796亿元，累计核心利润约9.382亿元，较上年同期约8.842亿元多0.540亿元。2025年前三季已可比核心率约54.2%，2026年当期约49.9%。在核心率下降时，报告营业利润约12.260亿元的增长不能证明控制软件单位净经济性同步改善。两个累计期间用各自季报核库存和成本，年化存货天数从约166至216天，虽受季末订单和采购排程扰动，仍支持在预测中保留营运资本约束。若按季末而非同日上年比较，又会混合节假交付、回款和年末资产处理差异。

## 历史观测进入模型的边界

模型从2025完整年报出发，合并2026年前三季实际与四季度情景。七个完整年可以识别早期扩张、2022年压力、其后配套扩张。年份数量覆盖经营阶段，驱动资料可比范围更窄，控制和硬件的已核直接产销桥以2024—2025年为校准。集团成本费用、核心利润和贸易营运资本能成较长序列，客户级续购、同机型均价、保修、存货订单归属及海外不同信用期未形成公开年度连表。参数估计的方式是在有观测的字段上复算，再用现金范围保护无法直接识别的结构。用现有营业数据按配置拆份额的结果，仅能帮助找到待核的最可能方向。

在这个安排下，早期高毛利用来检验业务可复用性，2022年的现金反转用于把当年CFO与持续获利分开，2024—2025的产销和产品分类决定近端控制量及价格组合的约束，2026年季度扭转则抬高近期库存忧虑。需要增长且利润率恢复的估值路径，必须同时解释为何这一轮新增硬件收入的服务和占款不会抵消毛利。在报表期、产品行和融资因素均受控时，才可以把改变的一分钱价格写入下一版桥。

转换成本还必须用一次具体产品重划来检验。2024年报物理第26–27页将控制系统销量同比减少10.83%的主要原因归于部分产品升级时已将随动系统功能集成，此后旧的随动系统不需同批搭配。可用套数因硬件功能整合变少，客户仍可能用了更高配置设备。这正是控制套数不能与客户留存一一对应的直接原件。若把2024记录当纯需求回落并按原产品当量预估2025，不但会低估已有机型销售，也会在新配置采用率变化时误读价格。年报同处还交代由于组合销售增加，旧分类由产品转为解决方案并给上期同口径调整。因而2022应继续作为合并需求压力的验证，2024兼有构成和定义变化，为同型号量误差提供解释。模型用2025同名销量上限和后续可得机型采购作验证，不能仅因公告技术升级就抬高复购率。 [柏楚电子2024年年报产销量说明](https://static.cninfo.com.cn/finalpage/2025-04-03/1222993275.PDF#page=26)
