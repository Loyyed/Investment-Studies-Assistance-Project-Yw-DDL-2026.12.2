# 最强反证是吨卖出，资本仍收不回来

压力所指的具体经营解释是新品和新厂已有更大的制造空间，却要降价和赊销来填满。贷款本金和折旧已随产线出现，合格可售公斤仍没有及时形成较高单吨 EBIT。集团仍可报营收增长，纵然销量更多，退回货、库存增加、客户回款拖后和付款更贵一起降低经营现金。这组现象与公司能够让现有客户复购并不冲突，因此质疑应集中在新增资本生产同样利润需要多久，而不是笼统否定品牌和技术。它对估值基准的伤害从三个变量开始：额外售出吨增长相对于产能较慢，组均价与利润率不随规模修复，周转资本及融资价格长期高于同样收入需要。三项分别到收入、现金、折现和每股，在共同量纲下看能否到市场边界。

先辨别已发生的吨和集团收益。二〇二五实售四十六万七千八百七十点零七吨，生产四十五万六千二百一十九吨，期末库存量按同表为五万三千四百七十七点一〇吨。生产小于销售可与消耗过去库存或范围差异兼容，三行的物理读数不应互相挪用。该年同期酵母品族原表给收入约一百一十九亿四千八百八十三万六千一百五十三点六八元与成本八十一亿零二十二万四千六百六十五点九一元，收入减成本约三十八亿四千八百六十一万一千四百八十七点七七，除真实销量得八千二百二十五点八一元毛利每吨。序列用这个计算支持正常生产的税前毛利量级，单吨 EBIT 还要扣费用。本地新厂要求每吨长期 EBIT 九千七百多的情形，不能拿集团生产与现金规模的增量直接达成，须有更高净售价、实际可售比例和低制造成本共同支撑。

最能改进经营判断的是按同一个项目取四道门。第一看当期资金报表的现金工程付款与资产进度，核清设计产能、工程辅助、开始调试和为外部客户交付的时间。第二查适用资质和单规格客户验证，记录能卖给多少客户、SKU、应用或地区，工程转固和可售分两列。第三对分季度实际可用产能、作业率、合格吨、卖出吨、当地售价和材料能耗拆经营毛利，确认一次性试车费有没有进经营利润。第四用递交发票至客户支付的天数和逾期款、退款、期末真实存货及已经支付的新增资本归集现金。这些数据应该是同一物理对象，不能拿新厂产量与集团平均价、另一国所得税和母公司内部收款拼成相对收益。

将印尼做条件检验可以知道哪项数据最值钱。保持总资本约八百三十三点三六百万元、经营税百分之二十一点五、目标新增回报约百分之十一点七五，对应税前 EBIT 约一百二十四点七九百万元。如果认证后可售占产能百分之五十、设备利用率仅百分之七十，有七千可售吨，所需 EBIT/吨约一万七千八百二十七元。若认证达百分之七十五且利用率百分之八十五，一万二千七百五十吨需要约九千七百八十七元。即使两比例均百分之百，规则下两万吨对应约六千二百三十九元。新的项目若实际收款条件需要六十百万元资金，固定合格和利用率下要多投入三十百万元，目标税后利润提高约三点五三。这样可以据下一份更精确合格吨或库存买料决定是提高体量输入还是改周转占用。它能排除只凭名义产能和单一吨毛利确定目标的做法。

资本权利在工厂层也要看清。中期的子公司清单给印尼法人持有权益百分之八十。园区建设按合并纳入经营如果服务的是非全资子公司，企业价值损益要先全额列到合并业务，随后对应少数股东对未来分配的份额，普通股每股不能直接收到该厂全部税后现金。若一个控制项目中以集团相互交付原材料、设备支援和客户转单，收入抵消并保留实际费用节约；无内部货物和资金匹配时，条件计算先设增量资本和工作资金的非重叠范围。同一个期末的售货使用比变好的独立证据，会影响母公司股份的价值，不能用“已控股”省掉资产利益约束。

对于在估值日后才公开的内容，关键是追踪预测兑现而保持对照日期。十一月十七日项目公告如提供调整预算、预计投资或收益，记录公开日和相对阶段十七冻结的数字，描述它判改的是产线成本、时间与规模哪一个。没有后续已付款原件，即使公司调整某个资本支出上限，也不能写其为实际多支出的全部现金。条件目标报的是计划回收或预计收益，与财报项目级 NOPAT/现金平均资本的新增 ROIC 不必一样，可能包括税率、累计现金、未收货款、固定资产使用期的不同。过去报告先写“预计”，下一次检测实际开工、运营在建和销量普及，再按不同情况重跑显式和稳定期。追回上次结论所需证据，用当时能知的公开资料对当日股价，保存此后数据检验，不混入历史股价。

市场价格的反方可以看成一张二维线。一端投资者相信现有折现低且项目现金回来，市场付的三十六点六二允许比基准更低的稳定资本回报；另一端公司实际信用、客户集中或汇率风险使融资资本加权成本接近百分之八，在固定现有经营下即便让新增回报达百分之十八，仍到不了收盘。每个中部折现率都对应可测试的单位经济。若有新的融资合同和市场风险对照支持百分之七点五的边际 WACC，目标新增回报约百分之十二。若最新项目销售规模和实际税后利润只能维持历史存量的约百分之八至九，未来稳定投入占用将高于基准。若昂贵资本和更低回收都成立，模型将接近压力区间，降低基准的依据不是当天价格跌，而是可比现金和项目证据改变了经营。

可以从价差算对市价约束有多严。在固定显式现金和 NOPAT、WACC 百分之八、允许回报最大百分之十八的边界，每股约三十四点二九，和三十六点六二相差约二点三三。乘现有八亿六千多万股，等价企业经营现值需要约二千零二十一点五百万元额外现金现值，若保持权益桥。这个补偿来自未来各年更多税后现金、较少早期营运投资或净资本现金支出，并不意味着单一年度可以按相同金额降低报表成本。要靠卖出的吨弥补，先区分是新增销量持续贡献还是营运资本提前回收，一次性的收款变化以发生期折现，无需赋永续年金。若债务和少数权益变化，目标的常量也随信息源真实变动，而不是由停在旧估值的股本倒推。

判断融资条件应先找区分解释的资料。最近报表里的存量借款利息测得的平均年化成本约百分之二点二六，受短长债、外汇和资本化利息因子影响。它比阶段十七新增贷款情景约百分之三点二低，说明平均旧融资未必贵；要决定以后投厂的真实风险，要查取新合同期限、币种、抵押和担保等具体新同等借款证据。权益成本里低样本 beta 曾因观察窗口变化而动得很大，管理口径“行业稳定”无法以单词替代市场结构估计。按项目投资地点和销售收款暴露，比较有条件的可比企业或行业的净现金不确定性，用希求收益的 WACC 敏感代替一段容易噪声的历史斜率。在股价判断上，新借款便宜而回款差只能提高早期选择空间，不能单独保证边际资本盈利。

把报告已能看明白的正证和反证连在一页。正证是酵母品族量增与产量工艺成熟，纵然组均价下降仍由单位成本把毛利拉升，地区出货和现有客户应用有规模。反证是增长吨并不自动转现金，二〇二六前三季 CFO 扣购建比上一年同期少约五百七十百万元，同时销售收现同比落后收入，年末前应收同比仍高。能消除第二组压力的最优材料不是一张新建完成照片，而是经产品、地区、产线可比后能证明当地复购、同一条件吨毛利、收款和必要库存的原始表。通过这组数据，决定把续购成本优势放在毛利或项目新增回报，把信用条款放在营运资本而不是增加销售折扣两次。

要追证据还有一个实际的源头套读方案。用年报合并利润表核营业收入与成本，再翻管理层产销量表核单位和本期列，检查生产、销售、库存数量是否倒置。用相同分部的销售成本和材料分项确定是否有产销存范围差别，以取得每吨产品收入、每吨主材与动力分项。读取三季报核收入、收现和应收资产表，用上年同期而非全年量做同比端点诊断。对半年度的在建表逐个校本期增加、内部转固、其他减少和期末余额，区分项目预算百分比与实际固定资产。最后把得到的设计吨、可售比例、税后 EBIT、资本现金与稳定条件在回代表里一次性贯通。若账本当前某条原件被替换或仍待签署，保留真实 ReviewStore 标签；算术、机制、市场条件估值和投资决定用各自实际状态，免得将模型阈值写为发行人事实。

若只有相邻年度数据，案例作者可合理完成量价成本组桥、集团现金变化及区域新增量的判断。对厂级收款、投产后的真实投入和原料替代成本，先用保守区间呈现，避免填读数给貌似精确的资本回报。较保守可以设合格率落到百分之五十、利用率百分之七十，测试每吨 EBIT 接近一万八千元的现实性；较有证据的下一步是核实际可售吨哪一档接近，以及应收信用给开工后现金多宽限。可同时估水解糖用自己产还是外买的进价之差，乘可替代合格用量，减能耗、新人和必要投入。若这项最后是内部供给，计算的经营作用是降低单位酵母成本；若外部卖，才以上客户净销售建独立收入。只看同项目成品能力无法两条都支持。

力求在新的报告使用清楚的投研取舍。早期投入在现金率之前见到、二〇一一至二〇一二报表增长和购建阴影、二〇二五成本恢复和现金同时改善、近期收现减速，构成四个互有反例的判断窗口。采用其中一段给稳定期参数，不应抹去另三段在压力测试的用途。现时较成熟业务给品牌和应用支持的复购一定价值，最低调的推断保持在已观察的绝对吨和单位利润。对跃升的可售吨量和更高边际回报要求明确可观测项目，重建股价让债务成本和回收一同达标。下一项最可能推翻当前看法的公开指标是新厂合格销售和分期收现，近似集团证据是前九个月销售收现缺口是否在第四季收回来。在百分之七点五融资条件与约百分之十二新增回报配对下，调查到哪项越线，证券判断就明确朝对应方向调整。

截至估值信息边界，主判断仍是存在可解释的重复采购和规模兑现，但普通股的价格差给融资成本和新项目收成更高风险权重。审阅者应核对现有基准更高意图是否已由真实的行业结构、投建节奏、客户回款和合并资本回报支持。若后续数据指向实际 WACC 约百分之八而本金必须通过信用销售消化，接受比收盘低的条件估值；反之若当地合格量和每吨 EBIT 在上述门槛之上并留出适当营运现金，保留基准高于市价的判断。卖得更多、经营利润更厚、实际现金更多三个结果在同一产线时间轴都成立，才足以共同推翻强反方。
