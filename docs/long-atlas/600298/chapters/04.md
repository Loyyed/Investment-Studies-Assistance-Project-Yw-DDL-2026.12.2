# 把发酵吨、区域交付和单位成本逐层对回集团

二〇二五年报给了产品、地区与渠道三个相互交叉的主营视图。同一批酵母可能同时落在国外、线下和深加工三个维度，不能相加当三笔收入。三个视图主营各约一万六千六百五十三点六八百万元，距合并一万六千七百二十八点八四约七十五点一七。主营成本一万二千五百二十六点零一，较合并一万二千五百九十五点七五少六十九点七四。读者可以按每个维度各加一次核校，再把合并差额单独查交易范围。二〇二四起食品原料从原其他品类单列，重建年度变化需将可比分组先合再拆。海外收入还受币种换算、本地工厂供货和出口份额影响，现有分组不足以把三者用具体金额拆开。

酵母及深加工销量和分产品报表的人民币数足以独立复算一条业务链。二〇二五年物理页十四到十五的产品主营收入和成本为本期合并对应品族的人民币元单位，销量表同一族为四十六万七千八百七十点零七吨；比较期为四十万三千九百一十四点六七吨。将收入除以对应吨后，二〇二四组均价约二万六千八百七十二元，二〇二五约二万五千五百三十九元。增量销量六万三千九百五十五点四吨，两期平均单价乘这个变化约一千六百七十五点九九百万元，各期均量乘单价下降约负五百八十一点二九。量×价交互一半分给两项，合计约一千零九十四点六九百万元，等于本期产品收入减上期。这一运算说明相同产品族内主要依靠规模消化，分规格订单证据不足时，组均价下降可能含高价用途占比下降。

毛利再多走一步。同期吨成本由约一万八千九百三十三到一万七千三百一十三元，吨毛利从大约七千九百四十提高到八千二百二十六。利用两期平均毛利与销量变化产生约五百一十六点九一百万元量贡献，组均价拖累五百八十一点二九，单位成本改善带来约七百零六点三三，合计增加约六百四十一点九五。若保持二〇二四单位成本，而其余比量算不变，量和组均价的两项相加会少约六十四点三八。也就是说产量扩大本身不充分解释毛利增强。组合、原料动力下降与设备利用对单位成本的解释同时成立，预测在可比近期吨成本行为得到验证后方可给更高单吨回报。

原料和动力有同一产品批次的观测方向。酵母品族二〇二五原材料总额多约六百一十七点二八百万元，折合每吨从约一万一千七百三十一降至一万一千四百四十七；动力总额少约一百四十四点七五百万元，折合每吨从约二千八百五十一降至二千一百五十二。制造费用每吨约从三千四百八十九到二千九百零九。单位制造费下降同时出货放大，支持更充分利用和工艺节约可能发挥作用。能源和原料采购合同的价格移动、新地区组合、前期采购库存的结转也可以给相同结果。缺分厂物耗、吨蒸汽价格和拉平汇兑的厂级成本表时，任何一项只能作为假设。上半年提到热回收、配比和发酵单产技术加强，从技术可能性到现金金额仍需同工厂可比每吨电汽、良品发货和折旧三项核验。

地区收入也能反推增长的分配。二〇二四主营国外约五千七百一十二点四〇，二〇二五约六千八百四十八点二一，多一千一百三十五点八一百万元；国内九千四百二十一点一六增到九千八百零五点四七，多三百八十四点三一。国外主营增量约占集团本年收入增量百分之七十四点一。以绝对额给规模方向，比用占比上升解释区域毛利更可靠；海外业务可以包括出口、当地企业、合营控制和内销后续再出口，汇率也改变报告人民币数。若有海外销量以当地工厂实际客户分类及两期币种参考价，可以把吨和价桥在同一交易范围重跑。对新厂从现有云贵、宜昌或外贸订单搬入一批销货，要把运费、库存和供货节约独立计入，集团合并收入只增真实外销量。

二〇二六要把累计、单季、余额与滚动分母各留自己的格子。前三季累计收入一万三千六百零七点九五百万元，比上年同期间一万一千七百八十六点四五多约一千八百二十一点五〇；第三季单季四千四百二十一点零三，是累计与中期之差及原季报合并的同义，不能再加一次。公开第三季未有同口径酵母族吨价或国外单季绝对分拆。若将累计增幅用于全年，必须假设第四季收入基数可匹配以及同一发运和收款季节性。业绩高增能支持模型的出货恢复方向，对各地产能利用率、每种酵母售价和生产吨销售吨差尚没有独立读数。第四季剩余的集团营业额推导用上年同季做参照，给不同放量及组均价分别设条件。

分析 EBIT 从毛利真正可用于现金前的一段。二〇二五集团营业收入约一万六千七百二十八点八四，成本一万二千五百九十五点七五，合并毛利约四千一百三十三点零九百万元；销售费用九百四十点六四、管理五百四十八点六八、研发六百七十六点八三，税金附加再扣后得到分析 EBIT 约一千八百三十四点四〇。报告营业利润约一千八百七十三点六三，原报告财务、投资、公允价值、其他收益、减值和处置方向按表调整。应进入核心支出的费用直接计过，非经营利息从经营现金和企业价值去掉，债务和权益现金桥另行对应。若公司向客户提供价格性补贴，收入确认和取得收入的销售支出要对同一条明细看发生归类，避免折让、代付或补贴重复。

研发对单位经济要按实际作用点安放。研发人员做新的菌种、适合的酶解、热能回收或客户应用，是否节省原材料或使下游愿付同品更高价，需要看技术转换成实际产出。集团二〇二五研发费用约六百七十六点八三百万元，约占营业收入百分之四点零五，分析利润重建已经扣一次。某项试验投钱放大单位成本，若其后显示能源单耗减小、售价和回款保持，单位现金可以获得改善。若直接把研发投入和毛利协同毛算为无成本成长，分析 EBIT 就会不符合已读报表。资本化开发支出若有明确项目、期限及总支出，在资本桥中与费用化的损益做投入核对，按现金付出和实际折旧处理，项目需求回落时相应压力反应在现金。

渠道毛利和利润的区别也可用一个可证伪的条件试想。若新增销售总额为一百百万元，正常化现金边际毛利参考同期线下或线上数据介于约二十三至三十一百万元，之后先减可分履约及技术服务，再减未在收入成本中计的退货、额外应收与场所支出。取条件新增渠道费用八、仓储净占用与购建五、其他未入账退换一，毛利区间只剩九至十七百万元供信用。在半年窗口均匀形成新增销量下，若其他设定合适，账期约十六点四到三十一天可把收益耗尽。这个区间是响应原账期与费归属可见性推出来的工作阈值，真正订单的信用销售期段、吨毛利与费用可能使计算完全改变。用集团平均应收端点三十多天去压它只做约束检查，无法充作某一新渠道的实际收款。

现金占款的另一个黑箱是存货。新的厂为了达到交付率会在认证前做试验备货或在能交付客户前把货留在库里。销售量增加时，库存额上升可以与成本吞吐更快同时出现；库存总额突增但终端交货和回款不跟，阶段间占用会积累。项目每吨的收益应以净外销并收到钱的一端校准，存货端点变少也要分消耗自有原料与向外部购货。在二〇二六年前三季，账面九月末存货增加约二百五十八点六四百万元而应付增加约一百五十五点零三，配合应收增加三百二十八点五二，简化贸易占用同比增四百三十二点一三。若将这笔钱误归入成本，利润会被扣第二遍；正确影响是扩大经营资本与显式现金流出，推低实际新增回报。

这些经营桥进入预测各有边界。需求由资格和可售吨先决定，组净价估计反映币种、地区和产品组合。制造及费用切给经营利润率，回款和补货决定多久收现金，工厂建设和在建采购决定增量资本。若吨价回落但每吨糖蜜、替代基质和动力也省下来，按实际各项金额更新退出比例；若销量高却收现跑不过，增加营运资本并重估增长现金和费用。直接对合并营业收入乘组合场景是没有厂级数据时的清晰代理；只要量价桥和厂级经营能解释它，就能将主要变动针到参数上，而不用把所有销量和营收一次归给某个公告项目。
