# 建成并不等于收款，资本回报取决于四道门

集团现金用当年分析经营利润一千八百三十四点四〇百万元起算。二〇二五年的模型正常经营税约三百九十四点四〇，得到 NOPAT 一千四百四十点零零。加已识别折旧摊销九百一十六点二一，减可见贸易营运资本变化七百一十三点六八和现金购买长期资产一千七百点五一，得到租赁与其他未解项以前的 FCFF 约负五十七点九八。报告经营现金二千四百七十七点九六扣同一资本支出约正七百七十七点四五，两者差约八百三十五点四三。公司并未报告这笔差是某一项目的收益，解释要从税费实际支付、销售预收与采购变动、非现金项目与资金分类近似展开。将两条桥同时校验，知道二〇二五现金增长能从报表复算，亦知道能分给具体项目的贸易资本模型留下未识别项。

现金税与折旧分类在多工厂环境特别重要。报告所得税发生在地区、企业实体和技术资质税率不同的利润基数，利润表还有非经营收入与融资费用。模型全国及海外简化税率基准百分之二十一点五作用于剔除非经营后的 EBIT，和按公司合并所得税费用除税前利润不同。若地方优惠在若干年内生效，只有公司能把适用资格与结束时间核对才能给单工厂降长期税；支付节点可受期初预缴和时差变化。项目若在建，工资、借款和折旧的支付及资本化会与资产可用时不同。确定价格前要以合并分析利润和净买建现金为边界，避免将已排入购建的支出又按“研发产线维护”重扣，折旧也只以加回抵消利润中的计算。

存量资本回报以分析税后利润除相邻年平均经营资本。二〇二五可见资本约一万七千四百六十二点九四百万元，上年为一万五千三百六十二点九二，平均约一万六千四百一十二点九三，税后利润一千四百四十点零零，所得百分之八点七七。若同口径二〇二四到二〇二五税后增加约二百五十七点四二除两年年末资本增加二千一百点〇三，得新增回报代理约百分之十二点二六。前者描述公司平均占用，后者估某段合并资本追加的短时效果，均不能由此写为新厂的未来 IRR。上年新投的设备可能带当年新增利润，而当年增加的在建可能下年才开工。估值稳定新增回报取百分之十一点二，接近较好的新增结果而高于较短的时段中位，需要未来认证与实际回款共同发现支持。

二〇二六前三季现金率受开始与结束时点影响。以三季报合并前九个月为单位，报告现金约一千七百一十二点四四，对比上年二千二百一十八点一三少五百零五点六九；同期间购建由一千二百四十点五一到一千三百零五点二六多六十四点七五。所以 CFO 减购建的近端差减约五百七十点四三。收现从一万三千六百四十六点二一到一万四千九百零五点一八增百分之九点二三，低于营业收入百分之十五点四五。到九月末集团贸易营运简化为应收加存货减应付从四千三百九十六点三八到四千八百二十八点五一，增四百三十二点一三。交易占用同比是一条资产余额，不是九个月现金变动的单一完整分解，因为现金同期还含其他科目。集团现金差与资本占用同向支持审慎账期，无法识别哪个项目资本回收已达管理目标。

期末余额除累计收入或成本得到的天数只作端点诊断。按九个月期间天数，二〇二五年九月末约十五亿三千万元应收对应约三十五点四三天，二〇二六同季约十八亿五千八百万元对应三十七点二八天。存货端点天数由约一百四十四点六七降到约一百三十一点九零，尽管余额增长百分之五点几。公司能通过成本吞吐加快消化库存，与发货时信用期加长同时发生。显式期模型以每年贸易营运占用为收入份额，在存货和应收各出现可归属信息时分开更新。如果新厂增加主动库存，早期预付采购和初期备库要作为项目投入，货物正常销售且回款后才有营运资本释放。该释放若只发生一次，应在某一过渡期体现。

二〇二六年中报物理页一〇九给项目预算、期初、本期增加、转固定资产、其他减少和期末人民币元。示范线一点一万吨酵母蛋白的期初约三百三十六点九九八百万元，加当期一百七十四点八〇七、转固约五百一十点〇八三，余额约一点七二二。三数直接代回，读者可复核资产变动，但批量可售、合格产品使用动向及实际回款没有跟在表中。八千五百吨特种酵母也转固约八十六点八二，而项目尾工和报表中合格批次能销售是两件事。要归属某项财务记录，确认它是最终造价、投入了多少现金和包含的工厂辅助线，预算额和期末在建额不能当作同样的营运现金。

印尼项目序列给比较案例。预算八百零三点三六百万元，项目两万吨，二〇二五年末已列约九十三点五一在建，与总预算对照约百分之十一点六四。二〇二六上半年本期增六十七点四三，期末约一百六十点九四；这一期间表没有给生产设备转固，按期初加当期可以对平。埃及两万吨扩建有小额部分转固约三点零六百万元，其中某些公司的生产资质与新增项目究竟谁对应，需要公司进一步说明。工厂按供货半径、目标产品、服务和运费节约分别影响销售及成本，两个项目要逐个核资格及实际产能，不能凭地区毛利证明所有项目都已盈利。

蛋白复配与功能水解糖项目在估值日以前已经可以用于条件分析。二〇二六年十月十七日的上市披露和十月二十七日股东会资料可核宜昌两万吨复配项目预算约一百三十五点二一百万元，拟二〇二七年八月开工、计划工期十五个月，预计收益率约百分之十六点五五；十一月三日有议案通过情况。功能水解糖对象用于原料替代、对外销售或供给计划，和酵母发酵吨的合并销售边界不同，在同年十二月假定开始的建设不可加到当季实际。另一项九月的白洋二期预算由约七百九十七点三九改为一千零六十点九九百万元，整项内含三点二万吨蛋白及联产预计二〇二八建成等，公告预计收益率约百分之十点七四。建设测算和建议是前瞻值；获批后如果有变更或合同公开，看实际发生、工程支付与认定时期，等到量和毛利达标再调项目输入。

项目回报的条件可以从工厂分子反推。以印尼设计两万吨，取可销售资格比例百分之七十五、设备利用率百分之八十五，实际可售一万二千七百五十吨；再设集团之外实质所需经营营运资本三十百万元，总资本约八百三十三点三六。保持阶段十七过渡期联动资本成本百分之七点五的市场边界回报百分之十一点七五四七，每年需要约九十七点九六百万元 NOPAT。用百分之二十一点五经营税换成约一百二十四点七九百万元 EBIT，除一万二千七百五十吨得约九千七百八十七元每可售吨。这个 EBIT 要在当地制造后，还扣区域服务、销售及管理和折旧；二〇二五集团酵母吨毛利八千二百二十六元虽为较成熟组合，作为只到毛利的比较已低于该 EBIT 必要值。若达产和贸易占用更好，则该门槛要下移，对当地产品的价格、良率和部分成本应单列。

用相同公式不替其他项目估值。示范线按已有资产规模和假定合格率估的每吨门槛约一万九千一百三十四元，复配线同口径约一千九百四十元，解释为资本投入差异、产品工序及销售用途变动，不支持同一种产品在一个厂亏而在另一个厂稳赚。复配若使用已经支付的上游蛋白、热能和厂房，单项目估值需要补实际内部服务成本或说明是集团资源的利用；过低资本额可能来自工程范围未覆盖整条链。若功能水解糖用于厂内，项目收益用少买外部底料成本和供给稳定折算，销量增加在合并内部并无外部计价。每个项目要求的是可回收分子及实际占用分母，汇总到股东再扣所属少数权益。

十一月十七日披露的相关园区预算调整属于估值日之后。它能使读者在新的阶段复访建设进度、项目规模、年度投资和资本开支是否落地；保持十一月十二日已披露的预算、研究假设和可得资料，不能倒灌到同日价值。以后若一期延后、替代原料有成本实证、海外项目在真实回款后利润改善，同一计划与后验分别列，修订只改能够定位的设备建设或贸易占用。若某期只给预计收益率及年内开工时间，就观察实际新增在建、生产和签单，继续以当时认证与单位毛利的条件资产来计算。对集团时间轴而言，最重要的是找到产线从可用到使用及净现金的间隔，不把所有建设叙述都同时移入未来吨量。

真实案例还可以拿季度环比识别备货与回收。已披露二〇二六年第三季单季经营现金逾十五亿元，同年一月至九月累计约十七亿元，差额意味着上半年经营净现金约两亿元。如果年度成长模型把前三季各季按平均收入现金率对待，会忽略采购、客户信用和收款集中在半年交界或第三季的时点。季度读数出现集中并不能优先支持“哪里又有一次新认定”的解释，因为既有客户也可能按照交付与现金协议在同一季度清账。使用秋季季报可先同比前九个月现金和同季应收，再看第四季分项；如果一笔账款本年已在三季到账，第四季预测就不应在基准中现金再收一次。同样若应付期比上年长，总体现金短期回升不会全部来自自身投用设备。利用这一解释能把年末过渡现金与日历切点联系起来，避免收益率估值误把收款行的月度集中作为终身回报的抬升。
