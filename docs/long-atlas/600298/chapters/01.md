# 安琪赚钱靠配方复购，估值兑现取决于可售吨和收款

安琪酵母已经证明，发酵产品和应用服务能让不同地区的产业客户形成重复采购。当前条件判断是二〇二六年十一月十二日上交所当地未复权收盘三十六点六二元低于五十七点七一元基准，价差只有在新增产线能按资格、可售吨与回款兑现资本收益时才有意义。当前增长主要来自销量与制造单位成本改善，组均价的证据不支持给全面提价定价。最强反方是为了消化爬坡产能进一步让价并延迟回款，同时融资成本上升；在明示经营条件下，这一组现实变化能把价值推到收盘以下。

在同日冻结的压力、基准和改善三条路径里，分别是十一点一二、五十七点七一和一百三十五点六七元。基准比收盘高约百分之五十七点六，压力价值比市场低约百分之六十九点六。三者的区间宽，因为稳定经营现金、资本成本和投资回收共同作用。终值现值占基准企业价值约百分之八十二点六四，表明折现和兑现年头对含风险资本的普通股影响大。阶段十五同日曾得到九十七点九一元，阶段十七已经把不够稳健的折现输入和回收条件改严。基准与现价的表面价差远小于原来，且本次补证作为条件检查，保留经纠错后的阶段十五旧值。

把一吨从设备推到现金需要走几个工序。资产先投入并转成可使用，产品批次还要通过适用质量、用途和客户工艺验证才具备可销售资格；能够销售的规格还需在本地取得订单、生产和交付，最后对账收款。每阶段都可能限制本期现金。二〇二六年上半年，一点一万吨酵母蛋白示范线转固约五百一十点零八百万元，期末在建约一点七二；印尼两万吨项目期末在建约一百六十点九四百万元，预算约八百零三点三六。两个工程的资产进度可定位，缺逐厂可售吨、合格率、每吨利润和付款记录。因此资产转固首先改变经营资本和折旧的归属时间，再由后续业务证据决定收入。把设计吨数一次加给已售吨，会让发酵产能和下一批能卖的产品发生重复。

二〇二五年酵母及深加工销量从约四十点三九万吨增加到四十六点七九万，吨组均价从约二万六千八百七十二降到二万五千五百三十九元，单位成本从约一万八千九百三十三降到一万七千三百一十三元。在两期量价平均计算下，销量带来约一千六百七十五点九九百万元收入，组均价与组合带来约负五百八十一点二九，合计增长约一千零九十四点六九。毛利变化中数量和单位成本贡献均为正。规模提升和工艺改良可能降低单位消耗，能源采购价格、原料结构、汇率和产品组合也能解释一部分。后续要看单位原料、动力和实际良品产出决定稳定利润率给哪一段，不能把这一轮全认作永久效率。

近期现金给前述机制一个独立检验。二〇二六年前三季度累计集团收入约一万三千六百零七点九五百万元，同比百分之十五点四五；经营现金一千七百一十二点四四，同比下降约百分之二十二点八。扣现金购建后一年前同期九百七十七点六二，本期四百零七点一九。九月末存货比上年同期增加约二百五十八点六四，但随成本规模变化估算的存货端点天数从约一百四十四点六七减少到一百三十一点九零；应收端点却从约三十五点四三升到三十七点二八。库存资金效率改善和客户账期压力可以同时成立，不能用“库存增加”单独解释当期现金走低。团队选该案例能直接用这组分歧测试长短期规模假设和营运资本公式。

最能把经营和股票价格联系起来的数字来自资本成本与新增回报联合检验。固定阶段十七显式现金、终值 NOPAT 和增长，以百分之七点五 WACC 折现，要在稳定期新增资本回报约百分之十二点零零一七才能回代三十六点六二元。若成本更高至百分之八，搜索回报率百分之八至十八，最有利组合每股三十四点二九，差二点三三元。公司可以用更好的显式经营现金弥补这段差额，或者以真实融资和区域风险数据说明百分之八偏高。再把达到百分之十二回报需要的新增吨和税后利润传给工厂，也能区分项目收益公告与已经产生的可收现金。

三条阅读路线各有一个目的。顺着交易和竞争走，解释工厂、经销商或工业团队为什么采购这类活性、配方服务和稳定交付，哪些认证带来真实转移成本。顺着历史、收入、成本和营运资本走，查看从早期扩张、资本质变到近期放量的证据，并把吨量和价格角色分清。沿显式期和折现走，则从二〇二六年公开数据、剩余期到二〇二七至三一和稳定年，复算 EBIT、税、营运资本、再投资、现金与每股，然后用近端项目核查决定用哪一组条件。每条路线能跳至同源报表和模型，来源状态取当前账本，事件日后的证据单独使用。

用年报会看到安琪的国际化不仅是销量规模，也是经营系统变化。当地工厂减少供应距离或运输时间，道路是审批、建立供应链、工艺稳定和客户试验的顺序；当地需求增长能让同一新增设施短期拥有市场，并不能自动解释应收高和合格品落地速度。投进去的现金必须要求每吨收入、制造和服务成本扣掉后还足以覆盖维持投资和客户信用。在这一前提下，资本回报与国际收入占比比单纯产能排名更适合选择估值情景。新一轮认证、销量及应收账龄披露出来以后，最有意义的做法是按项目和集团同时更新；明确哪组结果已经迫使单个参数转向，保留其他尚有支持的经营假设。
