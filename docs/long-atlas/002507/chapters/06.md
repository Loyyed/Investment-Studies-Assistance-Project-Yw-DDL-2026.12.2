# 由量价、费用和现金排布折回每股

估值冻结在二〇二六年十一月十二日深圳市场收盘，三季报已披露的九个月数据进实际段，剩余期接同口径二〇二五年第四季度和三条情景。全年收入的基准为二千五百零五点一九百万元，其中实际二千零六十七点五一，余期四百三十七点六八。全年分析 EBIT 七百六十六点九七，公开九个月六百三十七点八五，剩余期一百二十九点一二。公开九个月购建三百九十八点六九，全年条件四百八十三点五零。剩余期预算并不全属于估值日以后，模型将披露期到年末的现金按剩余天数比例切割，约百分之五十三点二六。这个比例采用近似均布；工程付款若有合同级付款日，按匹配日期重算更精确，不能把已经花掉或收到的钱留给十一月十二日后的投资者。

从二〇二七到二〇二九年，基准先设出货销量代理每年约百分之三点一二和组均价及结构百分之零点八，综合营收增约百分之三点九四。乘数而非单纯相加，以期初收入乘销量变化作为量项，再用新销售基数乘价格结构变化；与历史中点桥的归属不同，两条做法都能回到同一增收。二〇二七以现有全年估计为出发点，量贡献约七十八点一一、价结构约二十点六七百万元，合并收入二千六百零三点九六。以约百分之三十点〇六分析 EBIT 率计七百八十二点六九，经营税一百六十四点三六，NOPAT 六百一十八点三二。再加折旧摊销一百零一点二五，扣购建三百九十三点二零、贸易营运资本增量四点五九、独立营运租赁二点六一，得 FCFF 三百一十九点一九百万元。这条工作表体现一个小幅销量增加经过价格、费用与较大现金投资后不可能都进入股东可分配价值。

按同一方法，二〇二八收入二千七百零六点六三、分析 EBIT 七百九十八点四六、FCFF 四百零七点四零。二〇二九三项变为二千八百一十三点三四、八百二十九点九四、五百二十三点九一。二〇三〇收入二千九百一十三点三零、EBIT 八百六十点一四、FCFF 六百零八点八二；二〇三一三项三千零五点四六、八百八十八点零九、五百九十九点八四。最后两个年份销量和价格结构增速开始接近稳态；FCFF 在收入上升下略回落，来源于过渡期资本与营运安排和折旧，不以固定百分比乘收入。样本用于预测收入的主要是近几年量价回验，价值上用二〇一九和近年购建对现金的冲击解释为何早期付出集中，余下模型分年数从预测表可复算。

压力前段销量代理约负百分之零点零八、组价及结构约百分之零点二。它假设渠道迁移和信用成本不降，主族恢复慢，利润率偏低且营运现金储备提高到六百五十百万元。对应二〇二七至二〇三一收入从二千四百六十九点零九到二千四百九十三点八八；FCFF 依次二百四十九点一一、二百八十四点七二、三百六十六点二五、四百四十三点四四、四百三十五点二五。改善以销量代理百分之五点一二、价格结构百分之一点二起步，兑现标准是旧线可见节约、经营中更高真实净销量并减少新增垫资。收入五年从二千六百九十二点六六到三千三百七十二点八四；FCFF 约四百一十一点九五、五百三十七点零九、六百八十五点七八、七百八十七点三二、七百八十七点二三。两条以相同股本和估值日比较不同经营兑现，可用披露周期的数据逐个否定或确认输入。

经营利润率由产品收入、单位成本和费用驱动决定其可辩护区间。预测底表以集团利润率先验和历史观测校正，基准主要落在百分之二十九点五附近，压力后段约百分之二十五，改善约百分之三十三。二〇二五单位材料成本变化支持在价格小幅波动时仍维持薄厚差异；最多决定核心单位盈利能保持，观察不到新直销费用便不能把二〇二五之前高利润率满额给新渠道。新增资金的集团占用和现金资产是公司不同的资产负债项。若直销只提高毛利但拉长账期，显式期增大营运资本；若销售费用被证实持续高于有效获客收益，调整经营费用和稳定 EBIT，使相同损失不重复列入多个经营变量。

资本成本不沿用安琪的单位 beta 条件。涪陵用估值日止约一百五十五周本股及沪深三百的价格序列回归，样本 beta 约零点八九六，解释力约百分之三十二点零二。向市场 beta 一收缩，给市场值约三分之一权重，得到约零点九三一。无风险利率百分之一点六、权益风险溢价百分之五点三二给股权成本约百分之六点五五一。基本没有金融债务，融资租赁仍按原桥作很小权重处理。三条经营情景的 WACC 变动仅来自这类桥的微差，约同在百分之六点五五一。这里的风险参数有历史依赖，若固定经营并反推匹配股价的 WACC，约百分之九点零八一。两者相距约二点五三个百分点，给大小明确的折现压力区间；它不是借贷成本或收益担保。

企业价值把每期实际可投时点自由现金按一个加权成本折返。二〇二七基准三百一十九点一九折成约二百九十七点零二，二〇二八四百零七点四零折成三百五十五点八零，二〇二九五百二十三点九一折成四百二十九点四二。二〇三〇、二〇三一相应现值约四百六十八点三四、四百三十三点零六，再加剩余期和后续过渡现金，基准显性期现值合计二千八百一十点三一百万元。终段收入增长收敛到百分之二，分析 EBIT 率到约百分之二十九点六二，NOPAT 七百五十四点九二。按增长除新增资本税后回报百分之十一点五，得再投资率约百分之十七点三九，终值首年现金约六百二十三点六三。除 WACC 与增长之差，再从过渡点折现得到约八千七百一十四点零一百万元，约占企业价值百分之七十五点六一。

基准净权益桥用货币资金二千九百点七四及合格金融资产三千四百九十一点七一，扣五百经营现金储备及约零点零七九融资租赁，净约五千八百九十二点三七。加企业价值一万一千五百二十四点三二得到普通股权益价值约一万七千四百一十六点六九百万元，除经济股数十一亿五千三百九十一万九千零二十八，得十五点零九三五一三〇八六七四六八八九元。行业相邻标的中海天、千禾有不同调味品结构及餐饮暴露，颐海国际有港股及关联餐饮客户条件。用同日股价及自身共同分母锚定，市值约一万三千一百七十七点七六与企业价值七千二百八十五点三九百万元；滚动核心 EBIT 七百一十三点九八、收入二千五百点八五、归母利润七百零八点九六，得十点二零倍 EV/核心 EBIT、二点九一倍 EV/收入、十八点五九倍 P/E。DCF 基准用相同 EBIT 分母约十六点一四倍，间距映射未来利润和现金的条件。

阶段十五冻结旧值正确是十三点九七九八〇七六四九六〇四〇八五元，阶段十七及沿用后的十五点零九三五一三〇八六七四六八八九，差约一点一一三七〇五四三七一四元。研究版本桥从历史参数和经营预测、再投资、折现、终值到权益项目逐步切换，后一步以之前已切换为条件，贡献有顺序。当前的渠道、基地和价格临界补证作为与冻结值平行的动态诊断，尚未取得实际数据要求改基准输入。阶段十七至本案例基准价值桥各步差为零，与阶段十五到十七数值变化并不矛盾。压力区间的下限与改写基准也各有不同记录。

直接把收盘代模型有三种经营含义。全利润率联动的冻结反解，在固定其余假设下要求稳定营业利润率约百分之十五点八六、对应稳定现金约三百三十三点九零百万元。单改终值 FCFF 并冻结显式期时，容许稳定现金损失约三百零三点三七百万元，临界稳定 FCFF 是基准六百二十三点六三减该值，约三百二十点二七。第三种让额外渠道费用和资本同时进入短期现金，用持续程度和资本安排界定是否存在根。旧矩阵在既定半年度额外费用零到三百百万元、额外资本零到一百百万元、费用三年衰减一、半与四分之一的范围，即便两者最重，每股约十四点三一，仍比市价高约二点八九，故原联合测试找不到价格根。已有现金阈值图可判断渠道增量在哪侧变负，渠道现金打平并不是企业股价打平。把局部现金的结论直接写成全企业市场根，才会造成图册和验收相互矛盾。

与原联合检验相比，新增敏感性给相同费用和资本诊断多接一段真实经营变量。固定冻结 WACC、权益桥和稳定增长、利润率及新增资本回报等参数，令集团显性期销量驱动的起始增速对基准偏移，搜索负十三到正三个百分点。偏移随成熟期逐步衰减，改变累计收入规模，稳定期的收入和 NOPAT 随之重算。与直销半年额外费用零、约七点六八、约二十一点零九百万元以及额外资本零、十、二十五百万元交叉，九个组合都能在区间找到根。以费用约七点六八及资本十的中间组验，销量增速要比基准低约十点三六三五个百分点，模型回代十一点四二元；搜索边界估值约十点六九及十六点四〇。九组根约在负十点四七到负十点一九个百分点。这些是相对冻结预测的集团销量偏移，未把费用确认为实际，也未把销量估值边界当作基地利用率或终端出货的观测。[渠道和集团销量联合回代](/long-atlas/002507/channel-current-price.csv)
