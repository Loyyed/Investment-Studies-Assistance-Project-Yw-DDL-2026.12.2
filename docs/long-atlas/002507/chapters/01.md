# 为什么一袋榨菜的利润要经过两次检验

涪陵榨菜能把稳定口味、常见规格和不断货的供给转成经销商复购，也能在成熟网络里把相当一部分利润收回现金。以二〇二六年十一月十二日深交所当地未复权收盘十一点四二元衡量，已验证的核心经营和可用现金支持较强的条件价值，现价给新品直销的费用与基地现金建设留出了缓冲。这个投资判断的约束是扩张必须服从回款和净投入纪律。若费用、占款与替代旧线的重复建设把稳定经营产生的现金推到市场临界线以下，老品有知名度也不足以保住每股价值。

同日三条路径从压力的十一点零零元到改善的十九点八七元，条件基准为十五点零九元。把两位小数保留用于阅读，全精度来自逐年现金模型。基准高出收盘约百分之三十二点二；压力值低出约百分之三点七。这两项差额属于模型输出和当天市场观察间的算术。基准给核心经销复购、低个位数的销量恢复、逐步下降的建设强度和较充足的权益现金余额定价。双边差距表达沿不同经营路径的现金结果；一旦长期毛利下滑、基地净重置开支和销售回款同步偏离，三个数也会沿新的可观测输入移动。

先把消费行为与公司报表放在相邻两端。顾客通常买的是一餐即食和熟悉的味型，结账发生在零售货架、线上订单或餐饮消费。公司账面先看到合同约定下向经销商或直销客户转移商品控制权。经销商预先配货能扩大货架可得性，也能在没有终端新需求时抬高某季出货。单季报表显示销售增长时，辨别销量、组均价和经销库存的组合比判断品牌是否“更强”更实在。经销商只在货架消耗补得过仓储、物流、垫资和返利时愿持续下单，复购发生的位置决定这条现金链是否有摩擦。

分别观察量、利润和占款能改变对二〇二五到二〇二六年的解释。二〇二五年榨菜品族收入增长约十五点零五百万元，吨量贡献七点三五，组均价与结构贡献七点七零。到二〇二六年上半年，榨菜品族收入多二十八点七九百万元，量带动三十二点一四，组均价与结构回吐三点三五。主族的恢复证据因此来自发货吨数和已实现收入；同规格终端提价或补库尚需要经销进销存和零售价交叉检验。若把两期增长都写成品牌提价，会把应当进入销售吨和回款的条件误填进长期价格与利润率。

直销能把本由中间层赚取的部分价差留在公司，代价是公司要承担更多履约和取得订单的成本。半年度披露允许独立算出直销多约四十八点二零百万元收入和二十一点零九百万元毛利。同期集团销售费用多三十四点三五百万元。若其中四分之一确因直销发生，再设新增应收三十天、其他经营占款及购建五百万元、超出净收入已反映部分的退换损失百分之一，增量现金就略为负数。结论的关键是费用是否可归属以及新增回款实际有多慢。当归属比例四分之一、其他条件不变，账期超过约二十六点五七天会使该渠道的半年毛利消失在向现金转换的途中。费用归属和账龄有了渠道交叉披露，可以替换这两个假设。

生产侧的验收是另一项独立检验。万吨级新线可以提高加工效率和环保合规水平，也可能把本能由现有厂完成的吨数移到新基地。以设计十六万吨、利用率百分之三十五、其中百分之八十替代旧线举例，名义五点六万吨中仅一万一千二百吨是可增销量。这时需要检查旧线究竟省了多少现金以及渠道能否卖掉新增吨。旧线每替代一吨少花五百元、每吨新增销售税前贡献按现有条件取六千多元，定期固定投入和维持性现金一亿元，仍略有缺口。在销额上直接加五点六万吨会把存量销售重复预测，在现金端也会高估扩厂的收益回收。

持有人获得的是普通股。股价与经营企业价值之间有公司可支配现金、合格金融资产、经营现金储备、融资义务和现有股份数等桥接项。估值日采用十一亿五千三百九十一万九千零二十八股，冻结基准权益桥为约五千八百九十二百万元。经营判断须先问渠道和基地如何影响现金，桥接时再核募投资金中哪些资本支出已排入企业经营预测。一笔现金若用于兑现预测已包含的工程付款，按既有统一口径处理；若额外在现金桥中全扣一次，估值变化的原因就成了两次入模。

本图册有三条可连续回到证据的路线。关注经销为什么愿意继续进货，顺读交易机制和扩张、承压、转折三段历史；关心量增是否还赚钱，从收入费用拆解走到现金与建设周期；准备复算股票价值，从二〇二六年已披露和剩余期出发按年折现，最后把市场收盘代回稳定现金和双变量压力测试。比较图把不同市场的股价放回各自币种，跨公司只比较同日差额率和回报口径。涪陵的主营格子、报表原行、期后跟踪和研究条件分开记录，用数时可以由产品、期间或变量定位。

读完七章，最值得拿着下次披露查的一条线是新增销售的回款是否到账，以及达到什么费用与账期组合后现金消失。若看不到公司单独披露直销应收，读者仍能检查集团应收、销售收现和销售费用与收入的相对变化，同时把渠道归属作为区间。二〇二六年九月末应收较上年同期多约二十二点七零百万元，也较同年初多约一百一十四点四一百万元。这种两种比较同时出现的状态要求控制季节性，账期是否越界要与同季终端补货、发货和回款一起解释。五月或八月的建设进展也只能使用估值截止前已公开部分进入当日定价，后续节点用来检验当时立下的条件。

行业增长和证券价值也要分开读。最初增加一个能稳定卖货的地区，能分摊生产和营销的一段固定成本；扩大已经铺到的城市，则往往需要提高单店周转或争夺邻品货架。因而同是百分之三的收入增加，前一种可能滞后提高资本周转，后一种也可能把回款和费用压住。在本案例给估值较高一侧的情景，至少需要二者出现一个可辨结果：公司净发货量持续恢复，或在相同有效销量下配送、加工和促销更省钱。两项都不成立时，不能用更多促销后的发货替代增长。利润由卖了多少和每单位留下多少共同决定，现金再扣掉用来取得同一批交易的投入，最后剩余权利属于普通股。把这一短链和图表读数对照，留出窗口、预算和临界线便各有判断对象。
