# 从出货吨数到每一步真正留下的毛利

收入重建从同一期合并报表开始。二〇二五年合并收入二千四百三十一点九二、成本一千一百七十六点三八百万元。对应产品×渠道主营视图合计二千四百二十七点七七和一千一百七十点六二。两条链各有四点一五、五点七六百万元未分到主营格子。按产品合计和按渠道合计得到的是同一张主营表的两个方向，若再相加会把同一袋货算两遍。二〇二六年上半年主营合计一千三百六十三点五四和六百四十点零七，与合并之差为一点九二和二点五三百万元。较小的差额仍能改变某些小品类的毛利判断，故列到对账差额，不能平均分给经销和直销。

合并表给全年量价的总边界，主营表给同族销售模式和毛利边界，销量表给吨数。二〇二五年主族榨菜由约十一点一四万到十一点一八万吨，增销约四百吨，和产品行得到的收入差十五点零五百万元核对。相邻期量与组均价都在变，桥将两期均价的平均乘吨变，称作量的贡献；两期销量的平均乘组均价变化为价及结构贡献，交互影响均分。由万吨换成吨再按一百万除回百万元后，主族量贡献七点三五、价及结构七点七零。其他品类收入多三十四点一九，吨量约贡献三十二点九三，组均价约一点二六。泡菜在息掉的二十点三六百万元量贡献上收回约四点六零价格结构贡献。分品类这些符号方向本身与集团混合吨价不同。

同样手法算二〇二六年上半年能观察到引擎改变。主族五万九千三百吨增到六万一千吨，组均价从约每吨一万八千九百三十一元降到一万八千八百七十六元。以两期价格均值乘一千七百吨得到约三十二点一四百万元，价格结构部分约负三点三五，合为约二十八点七九。集团同期其他产品的吨数从二千七百吨变四千一百，价与结构和销量一起改善，收入约多四十点八五；吨成本也从约九千零三十一元走到一万三千八百一十二。有的新增销售价格水平会上移，而成本增幅分走了新增毛利。萝卜少一百吨但组均价下降更显著，泡菜的约六百吨下降几乎解释了全部收入减少。给预测加一个平均涨价不能复现这四条流向。

毛利桥同样采取量价中点归属，但再给单位成本一条路径。二〇二五年榨菜毛利变化由量贡献正四点零六、组均价及结构正七点七零、单位成本改善正二十二点零三百万元组成。二〇二六年上半年主族毛利则由量贡献正十八点五七、组均价及结构负三点三五、单位成本上移负五点一三构成。同期期末价比上年减少约五十六元一吨，成本多约八十五元，吨毛利少约一百四十一元。量增支撑毛利额，但当前吨边际利润较上年同期弱。将这一变化用于收入和 EBIT，需要同时设低个位数销量恢复、小幅组价及结构增幅和高于销售规模的费用占用条件；当前报告的组价负值值得解释为何基准还有正的结构项。

食品加工成本表里，二〇二五年的材料约七百九十五点零一百万元，比上年少二十二点六三；工资约一百三十七点八二，多九点四零；制造一百一十三点四三，多六点六七；运输八十五点三六，多七点二八；动力三十九点零零，多二点三七。由当期减上期理解成本符号，底表个别列以节约为正要读对应表头。材料下降大体被其他科目变化吸收，集团营业成本仍多六点四一百万元。集团毛利增长约三十八点三九，销售费用多五十九点三九。这说明即使工厂材料或库存结转改善，公司为取得销售和经营扩张付的钱大于当期毛利改善。毛利变好给模型售价或单位成本一段支持，销售从毛利到经营利润的传递在这一年不能按常数减费处理。

半年替换年份看到材料与人工起到不同作用。二〇二六年上半年食品加工原材料约四百四十五点五四百万元，对上年四百一十三点零六，多三十二点四八。同期工资多约四点七九、动力多一点五〇，运输约少零点三五百万元。集团这一半年中不同品类的吨成本走势并不整齐，食品加工材料总额还含吨数上升，买入价格、前期库存结转和消耗时点也会变，故不能把增量原料额直接归给当期涨价。去做相同产品吨耗和原料采购成本的对照需生产、销售、在制和库存的四组量，年报目前只够从销售成本配吨作判断。后续理解新基地的材料节约，也要查同季产量和品质是否可比，把采购变动与制程节约分开。

集团二〇二五年报告营业利润约九百一十六点一一、分析 EBIT 七百三十五点四五百万元。后一个数通过营业收入扣营业成本、税金及销售、管理、研发等经营费用重建，方便把商业模式和现金联系起来。报告财务费用约负八十八点九七，原表减去负的费用相当于增加报告利润，重建分析 EBIT 冲掉这一部分。再扣报告中的其他收益十四点八七、投资收益七十二点五八、公允价值增益五点六九和少量处置收益，对已计报告的信用和资产减值分别按实际负损失符号反向调整。货币资金的利息与到期处置收益用权益桥讨论，防止以经营现金永续后又加一遍生成它的资产。期间费用已在重建公式扣过，原报至分析的调整表属于对读，不能再附加一次。

以二〇二六年半年度报告销售模式表物理页十三的本期和上期收入成本列作为独立复核。计算时分别对四个直销产品做本期收入减成本、上年同期收入减成本，再相减得榨菜十三点二三四五四六四、萝卜零点六一零七八五七四、泡菜零点零八零四七三四七、其他七点一六一八四九八九百万元。四项相加为二十一点零八七六五五五。有些汇总写二十一点零九，同一精度口径。接着相加四格收入差二十四点一五七四五七〇九、一点三二一八三九二二、零点五六三二二七一八和二十二点一五二九八八〇二，得四十八点一九五五一一五一百万元。毛利增量除增收约百分之四十三点七五，描述混合新增交易每元留下的毛利，不能直接当期末全部直销的平均率。

在经销格走同一操作，收入合计多约四点四二、毛利少约七点五二百万元。榨菜经销收入多约四点六三，收入规模按中点毛利率给予正二点六九百万元，但格内毛利率变化引起负五点八三，合计约负三点一四。这为阶段性外层成本或产品结构不利提供方向。其他经销类虽增收约十八点七零，格内毛利率变化也带来负四点四一。相反，其他直销类毛利率格内变动贡献正二点零三。企业能通过直营与分销调配货物，也可能有不同消费和促销，因此渠道汇总增量不等于新客增量。恢复两类渠道同一产品销售份额时还要检查经销减少是否直销新增的来源，避免把渠道搬运写为需求增长。

接着把直销从新增毛利推到可留现金。令本次渠道净新增应收是新增年内营业额四十八点一九五五一一五一百万元乘账期天数再除半年一百八十二点五天，三十天约七点九二。令未在净收入反映的额外退换按增收百分之一取零点四八，令库存减应付、押金、营运租赁和新增购建的其他净合计为五。三项都在同一半年口径从新增毛利减，得费用至多约七点六八三一五百万元。再除同期集团销售费用增量三十四点三五零九三，得费用可归属上限约百分之二十二点三七。用集团费用作分母给投资者观测方向，模型里实际优先从渠道台账取可归属履约和获客费用。

这条桥可转为两个互补的测试。若判断集团增量费用四分之一因直销增加，费用约八点五九百万元，剩余用于新增应收的空间约七点零二百万元，逆求天数约二十六点五七。若费用归属半数，现金缺口在三十天时约九点四九百万元，甚至零天应收也覆盖不了其他条件。若渠道改善回款，模型改变贸易营运额及期末新增现金，而不会直接给毛利率加一点。若渠道需长年多承担营销和履约，需给营业费用永久化并置于税后现金稳定段。一次进入渠道买设备的资本占用属于近期经营再投资，不能按销售费用的永久倍数处理。

把两期毛利和费用联起来，可以把当前直销解释约束在相当窄的一组要素。已看到的是部分格子毛利改善、经销榨菜格内承压、集团销售费用增量比直销毛利增量还大。要支持直营渠道拥有更高净贡献，用实际可分费、库存、应收以及退换代替情景占款；同季单位回收数据自然对出货和终端购买作交叉检验。若现有直销增量现金负，核心经销盈利仍在，理由是近期渠道费用及应收不必永久以相同方式扩张。模型用费用和占款冲击持续期的边界与长期现金损失阈值分列这一决定。资产部分的新场地是否代替原场地，则按下一章建设资本和供货能力另外验收。

另一条来自附注的复核显示，成交和企业确认收入几乎都发生在一个时点。二〇二五年报物理页一百三十四至一百三十五的营业收入与成本附注，在本期发生额、上期发生额之间按收入和成本拆列。二〇二五主营收入为 2,427,770,194.01 元、主营成本为 1,170,621,655.16 元，其他业务相应只有 4,152,586.16 元和 5,760,404.17 元。由此能看出全公司销售收入虽比主营大，其他业务贡献当期为负，不能给第二条可持续收入直接套主营毛利。按收入确认时点分组，本年约二十四点三二亿元收入中，仅约二十点四八万元计在一段时间内；前者首先说明公司的交付凭证与对直接客户的控制权转移关系，仍需要阅读对应零售渠道的实际销货判断终端需求。原表还披露当期从合同负债年初余额确认约五千三百零一点二七万元收入，表明结账与发运的先后顺序在部分业务里确实不同。以这一条独立的报表证据校准模型，预收消耗先减少负债、增加收入；若要跟踪现金，把账期新发放与预收消化分列，不能把两种前置行为都称作消费者增加购买。

半年报还提供了比集团直销合计更接近交易的一层。物理页十五线上直销四个产品本期收入合计 81,318,834.84 元、成本 42,086,529.33 元，上年同期分别为 47,320,237.76 和 24,759,410.71 元。按同样的毛利相减，线上新增约十六点六七百万元，占全部直销新增毛利约百分之七十九点一；增收约三十四点〇〇百万元。用全直销表减该视图，线下直销增收约十四点二〇、增毛利约四点四二百万元，这两项为算术残差。抖音一行约多二十三点〇六百万元收入和十三点四〇毛利，属于四个品类之下的另一种视图，不能再加到线上。电商规格和平台组合解释了部分增量，哪类产品在促销结束后还能有同买家复购，要用后续同平台实际包数和净销售检验。

同一半年报物理页二十二销售费用明细和物理页九十八利润表附注都提供了更具体的费用路线。人民币元的本期与上期中，市场推广费 124,924,012.57 对 97,459,327.61，增约二十七点四六百万元；电商费用 20,246,716.39 对 12,525,524.19，增约七点七二。发行人把电商费用上升联系到新品引流，公开合并科目仍有按订单类别、平台、折扣、代履约和结算节奏的归属缺口。若将电商费用增加全给同口径线上直销新增，三十天应收、额外百分之一退换、五百万元其他占款及购建，线上费用上限约五点七四百万元，已可见费用多约七点七二会使增量现金短约一点九八；用同样其他条件反算，新增账期约十九点三八天就打平。条件计算中的退换只取超出净收入已体现的损失。这给了比按合并销售费用平均摊配更接近真实获客费用的压力检验；若按额外费用中的部分可归属或直销提前回款，可以用底表重算。

物理页十四同一报告还给上期末及本期末一级经销和联盟商由二千四百四十二到二千三百四十六个，与部分地区优化同时发生。前五大经销客户半年收入约一百七十一点二八百万元，期末应收约三十九点八六；以半年天数乘余额除同期收入，端点代理约四十二点四八天。原件对经销结算写先款后货加部分授信，名单数量下降不自动等于销售弹性下降；大客户的这些应收证明集团账期变化也可能来自经销，而非一定落在加快的直销。将此作为集团应收同比增长的另一个竞争解释，能够避免把已经能看到的电商费和主要经销信用同时全算成直销费用。确切区分需要按销售模式披露信用销售、回款年龄和集团共同营销的去向。[二〇二六年半年报原件及本期比较列](https://static.cninfo.com.cn/finalpage/2026-08-28/1225517908.PDF)
