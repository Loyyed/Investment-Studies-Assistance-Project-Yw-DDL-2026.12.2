# 经营利润之后，是季节占款和基地投付

一笔出厂销售确认当天可以增加营业收入，企业要等收款、原料付款、加工费用和工程支付清楚才能计算可留给所有资本提供者的自由现金。用分析营业利润作起点，先扣经营现金税代理得到 NOPAT，随后加回生产资产折旧摊销，再扣贸易营运资本变化、现金购建及适用的经营租赁现金。造出同一批货的成本、垫在客户或仓库的钱、生产线买入价分别走不同路径。折旧已在成本或费用中减过，显式期限追加现金投资后要加回折旧；花钱在厂房的现金会再由购建扣掉。若年度报告成本或现金附注识别不了租赁分期，重建数称为租赁前或未识别项前的现金，留给报表 CFO 和差异两行检验。

二〇二五年这一串用原合并报表对得上。分析 EBIT 约七百三十五点四五百万元，按模型百分之二十一经营现金税率算税额一百五十四点四四，NOPAT 五百八十一点零一。年折旧摊销一百零九点八七，年度贸易营运资本增量约八十七点七五，现金购建四百一十二点三四。前三个现金调整相加减，租赁前 FCFF 账桥约一百九十点七八百万元。合并 CFO 六百五十七点二二减相同现金购建得到二百四十四点八八，比重建数约五十四点一零高。投入资本和利润桥采用分析范围，报告经营现金受付款时点、其他经营往来、补助收取和会计分类影响，差额可追踪而无须硬归入原料排产率或某渠道损失。

模型税率描述长期业务经营税负，报告所得税费率约百分之十五点六九的分母包含投资与非经营利润。税费现金的年度时点也不同于利润表所得税费用。在集团利润表无全部税务现金明细的情况下，不能把净利所含报告税率直接设成扩产期间边际税率。分析经营利润率同时扣除了合并营业税金及附加，所得税率只作用分析营业利润，不二次抵扣税附。若新厂或地区有已披露优惠，取得适用项目、计算基数及生效期间才在显式期按项目扣有效现金税；对应过渡到恒定税负的位置逐年可再核。

营运资本中心是库存、信用客户和供应商。榨菜采购受季节影响，库存包含新季原料、在制和能够供货的成品；采购付款相对销售现金可以跨期。集团年末可见贸易营运资本从二〇二四的三百三十三点八三升至二〇二五的四百二十一点五八百万元，分别约占年收入百分之十四点零和百分之十七点三。季度同比同阶段余额优于直接拿九月末对比年末判经营效率。二〇二六年九月末应收约一百四十三点五八，对年初二十九点一七增长约一百一十四点四一，也对上年同期期末约一百二十点八八增长二十二点七零。同时累计经营现金约六百九十一点二八、现金购建约三百九十八点六九，差额约二百九十二点五九。现金仍正和应收余额上升可以同时成立，直销压力要落到新增收款及合同上。

使用集团贸易营运资本代理不能看成取得某年每个经营零售户的周转。库存与应付相互抵会改变现金，预付款与合同负债也是资金渠道。此前年度底表保留按合并可见项做的库存加应收、减应付及约定经营余额，对账差表示分类范围和同期间其他经营往来。把第三季采购高峰当作全年永久库存需求或者拿年末较低应收做新增渠道基准，都能令现金预测摆动过大。基准将平稳期经营营运资本占收入设百分之十三点五，接近二〇二四较低水平且低于二〇二五年末约十七点三的水平。若未来同季数据显示期末贸易占款与信用逐步锁到更高份额，显式期先补增加的现金占用，稳定期新增回报也相应保守。

经营资本的金额还报告其他长期资产及使用权资产，有些完成工程已经转为固定资产，有些仍在建。对存量回报，以可计量 NOPAT 除相邻期末资本平均余额。二〇二五以五百八十一点零一除以约二千四百二十三点八七得百分之二十三点九七。对新增资本，拿同口径 NOPAT 的相邻年变化除以可见资本变化，得到约负百分之三点零二。二者不一样，因为生产和向经销商销售先后不同，且扩建在建资产不产生当期产量。稳定再投资回报的基准百分之十一点五低于成熟存量观测，也不把建设期负回报固定成永续。投产、净增量、单位节约、客户偿付与追加维护都有可观察时序，用来判断应该靠近哪一端。

新基地的一期设计十六万吨。二〇二六半年报在募集资金使用表列承诺投资二十七万七千六百二十六点四三万元，本期二万七千二百八十点五一万元，累计九万四千七百五十点二六万元，表列进度百分之三十四点一三，预计二〇二七年六月三十日达到可使用状态。预算减累计为十八万二千八百七十六点一七万元，也就是约一千八百二十八点七六百万元。现金流量表附注中基地实际购建采用元列，换算为约二百五十八点四九百万元，与募集资金本期变动二百七十二点八一不相同。募集资金项目表的投资进度、工厂实际投入、完成付款时点和转固可以一致发展，但数字口径仍有区别，逐期对账避免作为可用货币资金再扣全预算。

购建模型从二〇二六年全期的四百八十三点五零减已公布九个月三百九十八点六九，得后续全年模型购建八十四点八一百万元。二〇二七至二〇二九基准对应三百九十三点二零、二百九十五点零二与一百八十八点四九，约八百七十六点七一，四段合计约九百六十一点五二。将半年募资尚余一千八百二十八点七六减这一合计，得约八百六十七点二四的机械覆盖缺口。七到九月实际已花的基地部分、应付结算和维护性资产在比较两端不同，缺口当作条件压力上界，不能当董事会已形成的同日账外欠款。若压力条件为这笔数字一半或全额未入模型且三年按五成、三成、两成支付，按冻结 WACC 折现对每股分别拖累约零点三三四九和零点六六九八元，情景值约十四点七六、十四点四二。这个区间由现金支付直接进入，产能改善情景另选固定参数。

设计产能和净销售的换算以生产和旧线移退同时为约束。百分之三十五利用率乘十六万吨得五点六万吨名义产量。若八成替换旧厂，净增量一万一千二百吨，替代量四万四千八百吨。以每吨售价一万八千一百一十八元、毛利率百分之五十、额外渠道费百分之十五估算，每吨新销售税前现金贡献约六千三百四十一点三元，乘净增吨得七十一点零二百万元；若旧线每替代吨节五百元，另得二十二点四零。扣固定和维持现金一百百万元余负六点五八。如无旧线节约，余负二十八点九八；若每吨节约一千元，转正十五点八二。都未扣增长性购建、营运和税，使用时将这些还原到全年模型相应阶段。无旧线节约且替代率固定八成时，解决固定现金需要利用率约百分之四十九点二八。

资本时序有清晰的可证伪顺序。原材料储备和土建开支最先占用现金，设备安装完成才谈可使用与验收，需求调研和渠道合作决定真正释放多少净销售，客户付款决定销售是不是可分配现金。原厂的资产停用、人员和能源节约晚于搬迁，若两个厂在爬坡初期同时运行，短期现金支出可能高于稳态。首批产品销售、产线开工和募投达到某百分比都只能证明一个节点，后续公司一旦给出年度生产吨、旧线实际减少吨、能耗变化和回款，要在同一物料和规格下核算。一期最终形成新增生产还是替代及质量升级，体现在收入量与固定现金两条不同公式上。

显式期的资本曲线与稳态闭合尤为重要。当未来两三年购建仍分别在三百九十三、二百九十五和一百八十八百万元，而经营税后利润逐年上来，企业自由现金要等待支付回落。这种斜坡与历史高投资、低同期新增回报的特征相符。若预计二〇三〇年后资产投入下降到接近维护和增长需要，不能再把需更换的生产线和扩大存量原料周转假设为零。终值按稳增长除稳定新增回报给再投资率，再扣稳定经营租赁等已定义的现金口径，当前基准得到长期现金约六百二十三点六三百万元。生产利用率解释的是新增回报和所需真实投资，拆到集团 EBIT 与现金之后才能传给这个长期数。
